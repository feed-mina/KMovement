1. 진입

SDUI 메타데이터 API가 실패해도 로그인과 로그아웃 기본 버튼이 사라지지 않게 fallback을 둔다. 로그인·프로필 화면은 메타데이터와 분리된 정적 F7 화면으로 등록한다.

사용자 흐름

게스트→이메일/비밀번호 또는 카카오→HttpOnly 쿠키→/api/auth/me→프로필→로그아웃

웹 응답 본문에는 access/refresh token을 넣지 않는다. 모바일 클라이언트가 X-Platform: mobile을 명시한 경우만 기존 토큰 본문 계약을 유지한다.

시간 설정 수정

기준 통일Header와 같은 1024px 미만을 compact로 판정
기본 상태모바일 우선 SSR에서 접힘으로 시작
텍스트‘시간 설정’은 세로 한 글자씩 깨지지 않음
사용자 선택펼침/접힘은 localStorage에 저장
