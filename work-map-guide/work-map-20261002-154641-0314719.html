삭제 안전장치

삭제 직전 fetch 후 7개 원격 SHA가 조사 시점과 같은지 재검증하고, 각 tip이 통합 브랜치 ancestor인지 확인했습니다.

복구 방법

필요하면 통합 커밋의 부모 SHA에서 브랜치를 다시 만들 수 있습니다. 통합 브랜치를 삭제하지 않는 한 7개 tip 이력이 유지됩니다.

확인에 사용한 핵심 명령
  • git fetch origin --prune
  • git cherry -v origin/main <branch>
  • gh pr list --state all --head <branch>
  • git merge-base --is-ancestor <source-tip> <integration>
  • git diff --exit-code main integration/...
  • git ls-remote --heads origin
  • gh api repos/feed-mina/KMovement/git/ref/heads/...
