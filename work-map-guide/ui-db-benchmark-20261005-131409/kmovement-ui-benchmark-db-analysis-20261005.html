핵심 결론
현재 탐색 화면의 카드가 보인다고 해서 모두 KMovement DB에서 읽는 것은 아니다. ‘맛집·관광지·문화시설’은 Spring이 한국관광공사 TourAPI를 호출해 반환하고, ‘성지·성지 맛집·작품 필터’는 PostgreSQL의 검수 완료 데이터를 읽는다. Redis는 인증·캐시·사용량 제어 등에 쓰이지만 이 목록의 주 저장소는 아니다.

  • 검색어, 카테고리, 시·도, 시·군·구, 정렬

  • 초기/불러오는 중/성공/빈 결과/부분 실패/전체 실패
  • 지도 SDK 지연·실패, 목록만 성공한 상태
  • 필터 변경, 더보기, 저장, 상세 선택, 재시도
검증 기준
  • 360/390/768/960/1440px에서 글자 단위 세로 줄바꿈 없음
  • 카드 선택과 지도 핀이 서로 강조됨
  • 키보드 포커스·스크린리더 이름·44px 터치 영역

  • 사진 없음, 좌표 없음, 부분 실패를 숨기지 않음
  • Chroma 추천은 실제 연결 전 ‘AI 추천’으로 표시하지 않음
