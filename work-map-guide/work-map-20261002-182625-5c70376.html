KMovement 기능을 Hostinger에 한 단계씩 옮기는 순서

결론: 현재 웹 주소검색 검증 뒤에 Spring 기반을 먼저 세우고, 공개 읽기 → 로그인 → 사용자 쓰기 → 커뮤니티 → 경로 계산 → AI·비동기 순으로 기능을 연다. RunPod·고비용 미디어와 관리자 기능은 가장 마지막에 둔다.
