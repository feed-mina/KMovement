업데이트: 2026-10-25 / 공식 번호 연결·근거 기록·코스 조건 검사 구현 및 시험. 변경안 #293, 운영 적용 전.

**보류 5개를 뺀 92개 이름을 중복 없이 추가 후보로 잡고, 공식 대상 번호·정확한 지점·관계 근거·방문 시간·예산을 통과한 자료만 검색과 코스에 반영한다.**

## 3줄 줄거리

1. 기존 번호를 보존하고 콘텐츠–가수를 공식 번호로 연결해 가수·지점·행동 근거를 남긴다.
2. 방문 날짜의 휴무일·영업시간만 검사하고 미확인 시간·방문비를 임의로 채우지 않는다.
3. 아티스트·시간·방문비로 거른 후보로만 생성하고 결과 직전 재검사한다. 일반 전환은 직접 동의한다.

이번에 깊게 다룬 부분은 2번 관계 검증이다. 나머지는 연결 순서와 합격 기준을 제시한다.

## 이번 요청 반영 — 공식 번호·근거·방문 조건·추천 검사

**콘텐츠와 가수를 공식 번호로 연결하고, 가수·지점·행동 근거와 휴무일·영업시간·1인 장소 방문비를 확인한 후보로만 코스를 만들며 결과 직전에 다시 검사한다.**

## 1. 명단 실측과 중복 정리

읽기 전용으로 모든 등록 대상과 현재 연결 수를 추출한다. 0개인 대상도 결과에 남긴다. 이름상 후보 수 / 공식 번호 연결 수 / 관계 검증 수 / 방문 조건 확인 수 / 추천 가능 수를 따로 집계한다.

제공된 조회 예시는 실제 저장 항목 이름과 일부 다르므로 그대로 실행할 완성 명령이 아니다. 현재 저장 구조를 대조한 뒤 올바른 현황 조회를 작성해야 한다.

같은 대상의 다른 이름은 기존 번호에 연결하고, 그룹·개인 멤버·채널·프로그램을 자동 동일시하지 않는다. 같은 자료를 두 번 넣어도 등록 수와 관계 수가 늘지 않아야 한다.

## 3. 최신 자료와 방문 조건 보충

가수·지점·행동의 공식 근거를 나눠 기록한다. 영상 시각·문단 위치와 검수 기록이 필요하다. 앨범 사진·뮤직비디오·방문·게시물·협업을 구분하고, 그룹 관계를 개인에게 넘기지 않는다. 방문 가능 여부는 휴무일·영업시간만 확인한다. 시간·비용 미확인을 24시간·무료로 만들지 않는다.

## 4. 일정과 화면

공식 가수 번호·선택 날짜·방문비를 전달한다. 조건을 통과한 후보만으로 만들고 결과 직전 최신 자료를 다시 확인한다. 일반 전환 동의는 기본 선택 안 됨이며 검증된 가수 코스에 동의를 강요하지 않는다. 교통·숙박비와 예약 가능 여부는 검사 범위가 아니다. HTML 비교 화면은 코드 기반 재구성이며 운영 캡처가 아니다.

## 5. 검색과 공개

새 코스는 최신 기준 DB를 직접 읽는다. 기존 다국어 검색 사전과 새 관계 자료를 섞어 검색 기준이 깨지지 않도록 구분했다. 전체 그래프·검색 사전 재생성은 이번 완료 범위가 아니다. 웹·Spring 서버·AI 서버·데이터 구조는 각각 적용해야 하며 운영 반영 전이다.
