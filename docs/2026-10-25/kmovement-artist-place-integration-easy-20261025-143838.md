공식 채널의 영상 제목·설명·게시일은 후보 수집에 활용한다. 채널이 공식인지, 어느 지점인지, 어떤 행동인지 별도로 검토한다. 팬 글·지도 리뷰·검색 요약은 자동 검증 근거로 쓰지 않는다.

요일별 영업, 날짜 예외, 자정 넘김, 휴식 시간, 주문·입장 마감, 예약, 공개 출입을 나눠 기록한다. 미확인 값을 임의의 시간·무료·항상 방문 가능으로 채우지 않는다.

자료마다 마지막 확인일과 다음 재확인일을 남깁니다. 재확인 기한이 지나면 맞춤 추천에서 빼고 다시 확인합니다. 새로 내려받은 날을 사실 검토일로 바꾸지 않습니다.

관계는 촬영 / 콘텐츠 방문 / 게시물 언급·인증 / 기간 행사로 나눈다. 행사 종료와 장소 폐업은 관계 사실과 별도로 기록한다.

## 4. 일정과 화면

현재 소스의 공개 일정은 서울 당일치기 일반 장소 범위이며 아티스트와 여행 예산을 실제 맞춤 조건으로 반영하지 않는다. 웹의 길찾기 연결 성공과 AI 맞춤 일정 완성은 다른 결과다.

개선 순서: 공식 대상 번호 + 여행 날짜·출발시각·이동수단 → 검증 관계 → 정확한 지점·출입·체류 전체 영업시간 → 이동·체류·여행 예산 → 일정 생성 → 최신 자료 재검사.

여행 예산과 AI 사용 요금 제한을 혼동하지 않는다. 가격 미확인은 0원으로 계산하지 않는다. 조건에 맞는 장소가 없으면 이유를 표시하고 일반 코스로 바꿀지 사용자가 고른다.

HTML의 현재 화면은 소스 기반 설명용 재구성, 개선 화면은 미구현 예상 모형이다. 이름·가격·시간은 가상 예시이며 실제 추천이나 실제 캡처가 아니다.

## 5. 검색과 공개

기준 장부에서 검증된 자료의 판을 고정하고, 관계 지도와 실제 사용 중인 검색 사전을 같은 발행 번호로 새로 만든다. 기존 네 분야 사전과 공개 일정의 검색 사전이 다를 수 있으므로 옛 도구 하나의 재생성을 전체 갱신 완료로 간주하지 않는다.

대상 수·관계·철회·버전을 비교하고 일부만 성공하면 공개하지 않는다. 기존 정상 판을 유지하고, 검색에 옛 자료가 남아 있어도 결과 직전 현재 장부로 검증 철회를 반영한다. 과거 저장 코스는 당시 자료를 보존하며 현재 방문 제한은 별도 안내한다.

현재 자동 배포는 웹 전용이다. 데이터·Spring 서버·CPU 일정·검색 갱신은 각각 검증하고 같은 판을 읽는지 확인해야 한다. 기존 원본 삭제나 직접 전환은 이 문서 게시 작업에 포함하지 않는다.

## 합격 시험 — 아직 운영에서 실행하지 않은 기준

1. 명단 중복: 같은 자료를 두 번 등록 / 다른 이름으로 재등록 → 공식 대상 번호와 수가 늘지 않음
2. 다른 지점: 상호가 같고 주소는 다른 두 장소 / 50m 이내 다른 점포 → 서로 다른 지점으로 유지
3. 다른 이름: 연결 후 아티스트 표시 이름 변경 → 기존 장소·팔로우 연결 유지
4. 관계 미확인: 자동 승인만 있고 관계 출처·검토 기록 없음 → 맞춤 추천에서 제외, 조사 후보 보존
5. 콘텐츠와 출연자: 여러 출연자 중 한 명의 방문만 확인 → 다른 출연자에게 관계를 자동 상속하지 않음
6. 방문 시간: 휴무·휴식 시간·자정 이후·임시 휴무·입장 마감 → 체류 전체가 가능한 장소만 남음
7. 지난 행사: 종료된 팝업·지난 공연 / 상설 장소는 계속 영업 → 행사와 장소를 분리하고 종료 행사는 현재 일정에서 제외
8. 가격 자료 없음: 가격 미확인 / 일부 비용만 계산됨 → 예산 충족으로 확정하지 않고 부족한 항목 안내
9. 여행 예산: 이동·체류를 포함하면 예산을 넘는 코스 → 예산 범위를 충족하지 못한 결과 차단
10. 검색 갱신 실패: 새 관계 지도만 만들고 검색 사전은 갱신 실패 → 기존의 정상 판 유지, 중간 상태로 공개하지 않음
11. 검증 철회: 코스 생성 중 출처 철회·장소 폐업·시간 변경 → 결과 직전 최신 장부로 다시 걸러냄
12. 지역·동의: 미지원 지역 요청 / 일반 코스로 전환 필요 → 지원 범위 안내, 동의 자동 선택 금지

전체 평균 70%가 개별 관계 공개의 합격선은 아니다. 검증 확보율과 확인한 자료의 사실 정합률, 미확인을 구분한다.
