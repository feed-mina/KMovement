# KMovement 전체 로직 쉬운 안내서

기존: 화면, 여행 추천, 지도, 이야기방, 영상 만들기가 여러 곳에 나뉘어 있어 전체 흐름을 한눈에 보기 어려웠습니다.

개선: 사용자의 선택이 화면 담당, 여행 담당, 인공지능 담당, 저장 담당에게 어떤 순서로 전달되는지 하나의 지도로 묶었습니다.

결과: 문제가 생기면 “어느 일꾼까지 잘 갔는지”를 먼저 보고, 그 부분만 확인할 수 있습니다.

## 1. 시작하고 로그인하기

- 내가 할 일: 로그인하거나 손님으로 둘러봅니다.
- 뒤에서 하는 일: 사용자에게 맞는 메뉴와 단추만 골라 화면을 조립합니다.
- 완료 확인: 내 역할에 맞는 화면이 보이고, 들어갈 수 없는 곳은 막혀야 합니다.

## 2. 나만의 여행 만들기

이 서비스의 가장 중요한 길입니다.

1. 당일 또는 며칠인지 고릅니다.
2. 좋아하는 가수와 지역을 고릅니다.
3. 여행 목적과 예산을 고릅니다.
4. 관련 장소를 찾아 날짜별 계획을 만듭니다.
5. 지도에서 장소를 보고 상담창에 질문합니다.

- 내가 할 일: 원하는 항목을 고르고 다음으로 이동합니다.
- 뒤에서 하는 일: 서로 가까운 곳과 취향을 함께 생각해 여행 계획을 만듭니다.
- 완료 확인: 일정의 장소와 지도 표시가 맞고, 질문했을 때 지금 여행 내용을 알고 답해야 합니다.
- 문제가 생기면: 선택값 → 여행 결과 → 지도 위치 순으로 보고, 세 곳을 한꺼번에 고치지 않습니다.

## 3. 장소와 케이팝 둘러보기

- 내가 할 일: 지역과 종류를 고르고 마음에 드는 항목을 저장합니다.
- 뒤에서 하는 일: 공개가 허용된 장소, 가수, 행사와 상품만 골라 목록과 상세 정보를 합칩니다.
- 완료 확인: 목록과 상세 내용이 같고, 저장과 해제가 내 계정에만 반영되어야 합니다.

## 4. 이야기 나누고 만들기

- 내가 할 일: 글이나 사진을 올리고 처리 상태를 기다립니다.
- 뒤에서 하는 일: 글의 주인과 공개 상태를 확인하고, 오래 걸리는 사진·영상 작업은 줄을 세워 따로 처리합니다.
- 완료 확인: 내 글만 고칠 수 있고, 작업이 성공 또는 실패로 끝나며 결과가 연결되어야 합니다.

## 5. 안전하게 돌보기

- 내가 할 일: 바꾼 부분에 맞는 검사를 고르고 결과를 기록합니다.
- 작업자에게 전달: 어떤 화면에서 무엇을 눌렀고, 기대한 결과와 실제 결과가 무엇인지 알려줍니다.
- 완료 확인: 검사 통과, 실제 화면 확인, 배포 확인을 서로 다른 증거로 남깁니다.

## 현재 상태

- 확인됨: 전체 구조와 주요 기능의 연결을 저장소에서 확인했습니다.
- 이번에 하지 않음: 모든 검사를 실제로 돌리거나 서비스 화면에서 처음부터 끝까지 여행을 만들어 보지는 않았습니다.
- 아직 모름: 현재 운영 서버와 외부 서비스가 정상인지, 실제 데이터가 최신인지, 사용자가 결과를 받아들였는지는 별도 확인이 필요합니다.
