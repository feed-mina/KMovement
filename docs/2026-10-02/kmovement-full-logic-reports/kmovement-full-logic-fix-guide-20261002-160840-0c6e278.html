전체 코드에서 먼저 줄여야 할 위험

P1 · 테스트 범위 착시현재 CI는 Spring 전체 테스트를 돌리지 않고 Celery 관련 두 테스트 클래스만 실행합니다. 모바일 테스트도 루트 CI에 없습니다.
P1 · 운영 구성 드리프트웹은 두 백엔드 주소에 의존하고, README의 하이브리드 배포 설명과 실제 운영 버전은 별도 확인이 필요합니다.
P2 · 두 개의 화면 계약DB의 화면 메타데이터와 코드의 컴포넌트 등록표 중 하나만 바뀌면 화면이 조용히 빠질 수 있습니다.
P2 · 선택적 저장 실패추천 이력은 응답을 살리기 위해 best-effort로 저장됩니다. 사용자 화면 성공과 분석 데이터 저장 성공을 따로 관찰해야 합니다.
P2 · 외부 의존성지도·관광·LLM·파일·GPU 서비스 실패가 서로 다른 대체 경로를 사용합니다. 오류 분류와 요청 식별자를 유지해야 합니다.
P3 · 문서와 실측 분리이 보고서는 현재 코드 구조를 확인한 결과입니다. 전체 테스트, 브라우저 흐름, 운영 DB, 배포는 아직 검증하지 않았습니다.
