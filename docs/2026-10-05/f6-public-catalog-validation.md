- 상품: 기존 PostgreSQL 이름/브랜드 검색·승인·권리 필터를 유지한 `view=public` 읽기 응답. 출처·확인 시각·근거 등급·설명이 모두 있는 후보만 공개하고 부족하면 정상 빈 배열. 권리 미확인·위험 URL 링크는 숨긴다. 시간대 없는 기록은 임의 변환하지 않는다.

- 공개 화면은 저장 버튼을 제공하지 않는다. 업로드·분석 job·Chroma 확장·상품 저장·결제는 이번 구현 범위가 아니다.
