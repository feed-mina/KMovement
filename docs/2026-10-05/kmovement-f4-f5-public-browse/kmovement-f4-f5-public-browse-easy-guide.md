# KMovement F4·F5 공개 조회 쉬운 안내서

> 현재 상태: 계획 보고서만 작성 / 기능 수정·시험·배포는 아직 하지 않음

## 최종 목표

한 탐색 화면에서 **전국 맛집**과 **K-컬처 성지**를 지역별로 찾고, 한쪽이 고장 나도 다른 쪽은 계속 볼 수 있게 만든다.

## 핵심 한 줄

지금은 탐색 화면의 문은 열리지만 장소 목록을 가져오는 길이 막혀 있다. 공통 입구를 먼저 고친 뒤 맛집과 성지를 서로 다른 두 줄로 확인해야 한다.

다음 행동은 개발 도우미에게 **공통 입구 → 맛집 → 성지 → 두 기능 따로 확인** 순서로 부탁하는 것이다.

## 3줄 줄거리

1. 맛집과 성지는 같은 지역 버튼과 장소 카드를 함께 쓴다.
2. 맛집은 관광정보 제공처에서 받고, 성지는 검수에 통과한 KMovement 자료에서 받는다.
3. 함께 작업하되 맛집이 멈춰도 성지까지 멈추지 않도록 따로 켜고 확인한다.

지금 나는 **[맛집과 성지를 함께 공개하기] 중 [막힌 데이터 길 찾기]의 [수정 전 계획]**에 있다.

## 지금 확인한 모습

- 탐색 화면 주소는 열렸다.
- 지역 목록, 맛집 목록, 성지 목록, 작품 목록은 모두 오류가 났다.
- 맛집은 장소를 불러오지 못했다는 안내가 보일 수 있다.
- 성지는 서버가 고장 나도 작은 예시 목록이 대신 보여서 정상처럼 오해할 수 있다.
- K-POP 지역 안내에서 “성지 탐색하기”를 눌러도 처음에는 맛집이 선택될 수 있다.

## 두 기능을 같이 만드는 순서

```text
공통 입구 확인
  ↓
지역 선택을 한 번만 만들기
  ├─ 맛집: 목록 → 다음 장소 더 보기 → 오류 때 다시 시도
  └─ 성지: 승인 목록 → 작품/성지 맛집 고르기 → 지도·출처 보기
  ↓
맛집만 끄기 / 성지만 끄기 시험
  ↓
둘 다 통과하면 함께 공개
```

## F4 · 전국 맛집에서 할 일

### 현재 상황

처음 장소 묶음을 받아오는 준비는 있지만, “더 보기”가 실제 다음 장소 묶음을 새로 가져오지는 않는다. 맛집을 가져오는 연결 정보도 운영 환경에 아직 준비되지 않았다.

### 내가 할 일

지금 직접 할 일 없음.

### 도우미에게 부탁할 말

“지역과 시·군·구를 고르면 맛집을 보여주고, 더 보기를 누르면 앞과 다른 다음 장소가 나오게 해 주세요. 장소가 없을 때와 연결이 끊겼을 때를 다른 안내로 보여 주세요.”

### 끝났는지 확인하는 법

1. 서울을 고르면 서울 맛집이 나온다.
2. 종로구를 고르면 종로구 결과로 바뀐다.
3. 더 보기를 누르면 새 카드가 붙고 같은 장소가 겹치지 않는다.
4. 장소가 없는 경우와 오류가 난 경우의 문장이 다르다.
5. 이전에 받아 둔 자료를 보여주면 언제 받은 자료인지 알 수 있다.

## F5 · K-컬처 성지에서 할 일

### 현재 상황

승인된 성지만 보여주는 규칙은 준비돼 있다. 하지만 운영 목록은 현재 오류이고, 작은 예시 목록이 대신 나타나면 실제 운영 자료인지 알기 어렵다.

### 내가 할 일

구현 시작 전에 “종류”를 이번에는 **전체 성지 / 성지 맛집** 두 개로 할지 결정한다. K-POP·드라마·영화·예능까지 한 번에 나누는 일은 더 큰 작업이다.

### 도우미에게 부탁할 말

“검수에 통과한 성지만 보여 주세요. 지역과 작품을 고를 수 있게 하고, 성지 맛집만 따로 볼 수도 있게 해 주세요. 서버 오류를 예시 장소로 숨기지 말고 다시 시도할 수 있게 알려 주세요.”

### 끝났는지 확인하는 법

1. 성지 버튼을 누르면 맛집이 아니라 성지 목록이 나온다.
2. 지역을 바꾸면 그 지역의 승인된 성지만 나온다.
3. 작품이나 가수를 고르면 관련 장소만 남는다.
4. 성지 맛집을 고르면 식당·카페 촬영지만 나온다.
5. 상세 화면에 주소, 지도 위치, 추천 이유, 확인 가능한 출처가 나온다.
6. 검수 전 장소와 반려된 장소는 보이지 않는다.

## 함께 만들지만 꼭 따로 확인할 것

| 확인 장면 | 맛집 | 성지 |
|---|---|---|
| 기다리는 중 | 장소를 찾는 표시 | 승인 장소를 찾는 표시 |
| 결과 있음 | 맛집 카드 | 성지 카드 |
| 결과 없음 | 이 지역에 맛집 없음 | 이 조건에 승인 성지 없음 |
| 연결 오류 | 다시 시도 안내 | 다시 시도 안내 |
| 한쪽만 고장 | 성지는 계속 사용 | 맛집은 계속 사용 |

## Before / After

### Before · 지금 확인된 화면

```text
[서울] [종로구] [맛집] [성지]
           ↓
  장소를 불러오지 못했어요
  또는 작은 예시 목록이 대신 보임
```

### After · 만들고 나서 확인할 예상 화면

```text
[서울] [종로구] [맛집 ●] [성지]
  맛집 카드 24개
  [다음 장소 더 보기]

[서울] [종로구] [맛집] [성지 ●]
  [작품 찾기] [전체 성지 / 성지 맛집]
  승인된 성지 카드
```

After는 아직 만든 화면이나 실제 캡처가 아니라 **완료됐을 때의 확인 모형**이다.

## 멈춰야 하는 경우

- 맛집 연결용 비밀값이 화면이나 기록에 보인다.
- 검수 전 성지가 공개된다.
- 더 보기를 눌러 같은 장소만 반복된다.
- 성지 오류를 예시 목록으로 숨겨 정상처럼 보인다.
- 한 기능을 고치다가 주소검색이나 기존 웹 화면이 망가진다.

## 전체 완료 체크

- [ ] 서울과 다른 시·도의 맛집을 볼 수 있다.
- [ ] 실제 다음 장소 묶음을 불러온다.
- [ ] 승인된 성지만 볼 수 있다.
- [ ] 지역·작품·성지 맛집 선택이 작동한다.
- [ ] 맛집 오류와 성지 오류가 서로 영향을 주지 않는다.
- [ ] 컴퓨터와 휴대폰 너비에서 버튼과 카드가 읽힌다.
- [ ] 무엇을 배포했고 어떻게 되돌리는지 기록이 남는다.

## 이번에 실제로 한 일과 하지 않은 일

### 한 일

- 현재 화면과 네 가지 데이터 연결 상태 확인
- 맛집과 성지의 다른 데이터 출처 확인
- 함께 작업하면서 따로 검증하는 순서 작성

### 하지 않은 일

- 기능 수정
- 시험 실행
- 비밀값 입력
- 운영 배포
- PR 또는 main 반영
