# KMovement F2 모바일 주소검색 쉬운 안내서

> 기준: 2026-10-04 · 코드 분석 보고서 · 앱 수정과 배포는 하지 않음

정적 HTML 검사는 통과했다. 내장 브라우저의 로컬 런타임 자산 경로 오류로 클릭·키보드·좁은 화면 검증은 수행하지 못했다.

## 최종 목표

휴대폰에서 주소를 찾고 고른 뒤, 회원가입 칸에 우편번호와 도로명 주소가 정확히 들어가게 한다.

## 핵심 한 줄

휴대폰 화면과 실패할 때의 직접 입력 길은 이미 준비되어 있지만, Hostinger에서 실제 주소가 검색되는지는 아직 확인하지 않았다.

## 3줄 줄거리

1. 사용자가 휴대폰에서 주소를 두 글자 이상 입력하고 검색한다.
2. KMovement가 카카오 주소 찾기에 대신 물어보고, 쓸 수 있는 도로명 주소를 최대 열 개 보여준다.
3. 검색이 안 되더라도 직접 입력을 열어 회원가입을 계속할 수 있어야 한다.

지금 나는 [기능을 하나씩 Hostinger에 여는 전체 목표] 중 [F2 모바일 주소검색]의 [코드는 확인했고 실제 연결은 아직 하지 않은 지점]에 있다.

## 사용자가 지나가는 길

주소 찾기 열기 → 두 글자 이상 입력 → 주소 결과 보기 → 원하는 주소 선택 → 회원가입 칸에 반영

검색 결과가 없거나 오류가 나면:

주소 찾기 → 직접 입력 열기 → 우편번호 다섯 자리와 도로명 주소 입력 → 이 주소 사용

## 현재 확인된 것

- 두 글자보다 짧으면 검색하지 않고 안내하는 화면이 준비되어 있다.
- 주소 결과에서 도로명과 우편번호를 보여주는 화면이 준비되어 있다.
- 결과를 누르면 회원가입의 두 칸으로 값을 보내도록 연결되어 있다.
- 검색 실패가 회원가입 중단으로 이어지지 않도록 직접 입력이 준비되어 있다.

## 아직 확인하지 않은 것

- 실제 Hostinger에서 카카오 주소 결과를 받아오는지
- 결과가 없을 때 안내가 실제 휴대폰에서 잘 보이는지
- 카카오 쪽 오류와 휴대폰 인터넷 오류를 서로 안전하게 처리하는지
- 직접 입력한 값이 실제 회원가입 화면에 남는지
- 주소 찾기에 쓰는 비밀 열쇠가 휴대폰이나 기록에 보이지 않는지

## 완료 확인표

| 확인할 일 | 지금 상태 | 끝났다고 말할 기준 |
|---|---|---|
| 정상 검색 | 화면 준비, 실제 미확인 | 실제 주소와 우편번호가 보이고 선택됨 |
| 빈 결과 | 안내 준비, 실제 미확인 | 검색어 변경 또는 직접 입력 안내가 보임 |
| 카카오 쪽 오류 | 실패 안내 준비, 실제 미확인 | 서비스가 멈추지 않고 직접 입력 가능 |
| 휴대폰 인터넷 오류 | 실패 안내 준비, 실제 미확인 | 인터넷 오류를 알려주고 직접 입력 가능 |
| 직접 입력 | 화면 준비, 실제 미확인 | 우편번호와 주소가 회원가입 칸에 들어감 |

지금 직접 설정하거나 비밀값을 입력할 일은 없다. 개발자가 F2 시험판을 준비한 뒤 실제 휴대폰에서 다섯 경우를 함께 확인하면 된다.
