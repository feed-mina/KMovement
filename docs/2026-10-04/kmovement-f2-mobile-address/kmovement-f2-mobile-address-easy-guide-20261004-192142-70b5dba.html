Hostinger에서 실제로 쓰기 전 마지막 연결이 필요합니다

휴대폰 화면과 실패할 때의 직접 입력 길은 이미 준비되어 있습니다. 다음 행동은 개발자가 주소 찾기만 안전하게 열고 실제 휴대폰에서 다섯 가지 경우를 확인하는 것입니다.

코드에서 확인

화면과 선택

두 글자 이상 검색하고 결과를 누르면 우편번호와 도로명 주소가 입력칸으로 전달됩니다.

아직 미확인

실제 서비스

Hostinger 주소로 실제 검색되는지, 빈 결과와 인터넷 오류가 휴대폰에서 잘 안내되는지는 확인하지 않았습니다.

3줄 줄거리

  1. 사용자가 휴대폰에서 주소를 두 글자 이상 입력하고 검색합니다.
  2. KMovement가 카카오 주소 찾기에 대신 물어보고, 쓸 수 있는 도로명 주소를 최대 열 개 보여줍니다.
  3. 검색이 안 되더라도 직접 입력을 열어 회원가입을 계속할 수 있어야 합니다.

아직 모르는 것: 실제 Hostinger와 휴대폰에서 검색·빈 결과·외부 오류·인터넷 오류·직접 입력이 모두 같은 흐름으로 작동하는지.
확인하는 방법: 주소 찾기만 따로 연 시험판에서 위 다섯 경우를 한 번씩 실행하고 화면과 응답을 함께 남깁니다.
