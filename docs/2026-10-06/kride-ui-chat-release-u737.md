# KRIDE UI·영어/일본어 채팅 수정 및 배포 완료 보고서

2026-10-06. 제품 변경·운영 배포를 수행했다. 로그인한 실제 브라우저의 사용자 확인과 음성 기능은 별도 상태다.

## 결과

- 메인·K-pop·코스·마이에 공통 메뉴와 밝은 카드·브랜드 버튼 규칙을 적용했다. K-pop 안에 아티스트·이벤트·상품 진입을 연결했다.
- 마이의 종류별 저장 목록 바로가기, 빈 목록의 찾아보기, URL 기반 종류·페이지 복귀를 추가했다. 저장한 상품은 제목 검색 대신 동일 ID 상세로 연결하고 공개 승인·근거 정책을 재확인한다.
- 영어·일본어를 직접 등록한 텍스트 화면으로 열고 로그인·전송·중단·명시적 재시도·종료를 제공한다. Groq를 호출하는 CPU 경로에 연결하고 공통 비용·횟수·동시 요청 제한을 적용했다. 시험 계정만 활성화했다.
- 없는 아티스트 이미지 파일은 요청하지 않고 초기 글자로 대체한다. 위키·언론 링크를 공식 일정이라고 일괄 표기하던 이름은 중립적인 출처 안내로 수정했다.
- 모바일 더보기 메뉴가 화면 밖으로 나가는 문제를 해결하고 터치 높이를 48px로 맞췄다. 이동하면 메뉴가 닫힌다.

## 배포와 검증

기본 수정 PR #269 / 소스 928167cce94d9f5448be86f1887092b6fc7df8df를 웹·Spring·CPU에 배포했다. 배포 후 공개 HTTPS Origin과 내부 HTTP 주소가 다르다는 이유로 채팅 전송이 403으로 차단됨을 발견했다. PR #270 / 웹 추가 소스 9fe44e36da2618e876598d192138d6c7ddaf6ac1에서 공개 주소 설정 KRIDE_SITE_ORIGIN을 기준으로 검증하도록 고쳐 웹만 추가 배포했다. CPU·Spring 운영 이미지는 기본 배포 버전을 유지한다.

모든 대상 컨테이너 healthy, 기존 볼륨 보존 확인. 운영 DB 자료·개인 저장 테이블을 수정하거나 초기화하지 않았다. EC2 자동 배포는 대상 설정에 따라 skipped였다.

- 전체 웹 테스트 92개 파일 통과. 변경 관련 85개, 후속 메뉴·셸 9개, HTTPS 프록시 5개, 배포 계약 8개, CPU 채팅 9개, 상품 API 8개 통과. 재실행·중복 건수는 총합으로 주장하지 않는다.
- 기본 PR 실행 검사 7개 통과. 추가 PR의 CPU 체크아웃은 병합 후 refs/pull/270/merge 삭제로 실패했고, main 기준 수동 재검증은 통과했다. 다른 추가 검사와 웹 이미지 제작도 통과했다.
- 공개 운영 7개 화면을 390·1440px에서 열어 200, 공통 메뉴, 문서 가로 넘침 없음과 페이지 JavaScript 오류 0건을 확인했다. 실제 로그인한 마이·저장 화면은 조작 도구 문제로 직접 재현하지 못했고, 별도 검증 응답으로 UI를 확인했다.
- 실제 운영 CPU/Groq 응답: 영어 961ms, 일본어 1225ms에 첫 콘텐츠. 두 언어 완료, 두 연결 중단, 이후 재요청 모두 성공. 이는 내부 서버 API 측정이며 로그인한 브라우저의 첫 표시 시간과 다르다.
- 실제 공개 HTTPS 요청은 로그인 검사(401), 외부 Origin은 차단(403)됨을 확인했다. 익명 요청은 유료 공급자로 전달되지 않는다.

## UI 벤치마킹 반영

공식 자료를 근거로 비교했다. 경쟁 제품의 실제 로그인·저장 조작은 수행하지 않았다.

- [Airbnb](https://www.airbnb.com/help/article/1236): 저장하고 메뉴에서 다시 여는 흐름.
- [Ticketmaster](https://business.ticketmaster.com/press-release/ticketmasters-newest-app-update-makes-discovering-and-tracking-events-easier-and-more-personalized-than-ever/): Home·Watchlist·Favorites 역할 구분.
- [Weverse](https://weverse.io/notice/18877): 전역 및 아티스트별 상품 진입.

기능 진입 메뉴 A=3/D=0/U=0(N=3), 저장·추적 구분 A=2/D=0/U=1(N=3)로 잠정 다수. 빈 목록 CTA는 A=0/D=0/U=3인 KRIDE 요구 기반 보완이다. 밝은 테마와 48px 목표는 프로젝트 기준이며 업계 공통으로 주장하지 않는다.

입력: route section, 저장 kind/page, 안정된 itemRef, 언어 en/ja/ko. 상태: 로그인 확인·로그인 필요·전송·응답·중단·오류·재시도, 저장 조회·빈 목록·오류·비공개. 계정/언어 전환 시 이전 대화 요청을 중단한다. 개인 응답과 공개 탐색을 구분한다.

## 남은 확인

로그인한 실제 브라우저의 저장·삭제·뒤로 이동과 언어 응답 표시 시간은 사용자 확인 대기다. 음성 녹음, 출처 있는 F12 후보와 공개 상품 후보 데이터 준비는 별도 남은 작업이다. 현재 상품 공개 후보가 0개라는 사실을 가짜 상품으로 감추지 않았다. 사용자가 직접 터미널을 실행할 일은 없다.
