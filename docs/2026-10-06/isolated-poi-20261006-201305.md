# 격리 장소 재구축 파일럿 명세 v1

현재 단계: 준비 완료 / 정답 검수 및 실행 환경 완전 고정 전 / 검색 실험 미실행.

최종 목표는 원본 장소를 보존하고 검증된 다국어 검색 후보를 만드는 것이다. 이번에는 별도 폴더 `D:/KMovement/pilot-specs/isolated-poi-20261006-201305`에 데이터와 명세만 준비했다. 옛 Chroma DB와 운영에 연결하지 않았고, 모델을 불러오거나 색인을 만들지 않았다.

## 고정한 입력

- 원본 JSON을 바이트 그대로 별도 폴더에 보관. SHA256 `49110f8c6074a1028f687c448d1dda745ed313f5ec94e99d9cfd6af59547903c`. 복사 전후 원본 해시 동일.
- 40,664개 전체 ID 보존 원장: 파일럿1,000 + 표본 외 보존39,664. 삭제·수리 없음. PDF는 대상 외.
- 후보1,000개: 문화·K-pop·관광·음식 각250. 질문 기준 장소30개를 우선 포함한 뒤 분류별·주소 첫 토큰별 순회와 고정 hash 순서로 선택했다. 균형 실험 표본이며 전체 분포의 대표 표본이 아니다. 주소 첫 토큰은 행정구역 검증을 대신하지 않는다.
- 후보별 ID·원본 필드·선정 사유·문서A/C·문서 해시를 저장했다. 원본에 보이는 설명의 연예인 주장은 문서에 넣지 않았다. 결측을 임의로 보충하지 않았고 공개 적격 승인은 전부 false다.
- 표본의 빈 주소14개·좌표 범위 추가 확인3개는 연구 자료에 보존했으며 지도/공개 적격 승인이 아니다. 두 수의 중복은 합산하지 않는다.
- 문서 형식은 name/address/category/sub_category를 고정 순서로 한 줄씩 연결한 **새 논리 기준 형식**이다. UTF-8 LF, trim·대소문자·Unicode 정규화 없음. 파생 문자열의 null은 빈 값이며 원본 바이트는 유지된다. 과거 저장 문서 재현 실험이 아니다.

## 질문과 정답 후보

한국어·영어·일본어 각각 긍정30·부정10 = 총120문항. 언어별 개발20/보류평가20이다. 같은 장소의 번역 질문은 같은 분할에 배치했다. 이름·지역·유사 숙소 구분 질문을 포함한다. 현재 긍정셋은 이름 중심이며 이름 없는 여행 의도·광범위한 선호 검색 평가로 확대하면 안 된다. 다음 검수에서 이 범위를 확인하거나 새 버전으로 보강한다.

`questions-draft.json`의 expectedIdsDraft/relevanceDraft는 자료 대조로 만든 정답 **초안**이다. 원본의 같은 명칭·지역 후보를 포함했으나 번역 별칭·다른 이름의 동일 장소·동명이 장소 및 다른 유효 정답을 사람이 검수해야 한다. 독립 검수 완료는0개이며 점수 산출·통과 판정을 허용하지 않는다. 관련성은 현재 이진1/0 초안이고 검수가 바꾸면 새 버전의 기준도 함께 고정한다.

`review-sheet.csv`에서 approved_ids, relevance_grades, reviewer, review_status, notes를 채우도록 준비했다. 보류평가 질문도 검토용으로 공개되어 있으므로 비밀 시험셋은 아니다. 향후 보류평가 점수로 문구/기준을 조정하면 해당 평가셋을 폐기하고 새 버전으로 대체한다.

부정 질문은 가상 장소5종과 출처 없는 현재 가격·영업·예약·실시간 인물 위치·무료 보장 주장5종이다. 후자는 가까운 장소 후보 반환 자체가 실패가 아니라 근거 없는 주장 승인 여부를 검사한다. 개발/보류에 동일 문장의 번역이 갈라지지 않는다.

## 모델·라이브러리 고정 범위

E5-small revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`의 가중치·tokenizer·config 등10개 SHA가 이전 고정값과 일치했다. 모델 파일은 아직 실험 폴더로 복사하지 않았으며 불러오지 않았다.

주요 라이브러리 8개 배포본의 실제 파일 16,759개 SHA256과 설치된 전체 123개 배포본의 METADATA/RECORD 해시를 기록했다. 누락된 주요 파일0개. 버전: chromadb=1.5.9, huggingface_hub=1.33.0, numpy=2.4.6, safetensors=0.8.0, sentence-transformers=6.1.0, tokenizers=0.23.2, torch=2.14.1+cpu, transformers=5.18.0.

이는 완전한 재설치 lock이 아니다. 나머지 의존성의 실제 파일, Python DLL/표준 라이브러리, wheel 등 설치 원본 해시는 아직 완전히 고정하지 않았다. 현재 python.exe의 해시는 기록했지만 이것만으로 Python 런타임 전체를 증명하지 않는다. 모델/라이브러리를 별도 offline 환경에 복사·검증하고 전체 의존성 해시를 완성하기 전 실행 금지다. 라이브러리를 import하거나 다운로드하지 않았다.

## 비교 및 판정 기준 · 이번 점수가 아님

| 변형 | 문서 | 질문 | 비교 |
|---|---|---|---|
| A | 고정 문서A | 원문 | 새 표본 baseline |
| B | A와 동일 벡터 재사용 | query: + 원문 | 질문 형식만 변경 |
| C | passage: + 문서A | B와 동일 | 문서 형식만 변경 |

384차원·유한 float32·mean pooling·정규화·max512토큰. 잘린 문서 ID를 기록한다. 문서·질문·정답·모델·후보 집합을 동시에 바꾸지 않는다. 별칭을 검색 문서에 추가하는 실험은 이번 A/B/C 이후 별도 버전으로만 한다.

- 각 언어 보류평가 Recall@5≥0.80, nDCG@10≥0.70, A 대비 하락≤0.02. Recall은 해당 정답 집합 대비 top5 회수 비율의 질문별 평균이다. binary DCG는 rel/log2(rank+1), 동점은 ID 오름차순. 오류 질문을 계산에서 제외하지 않는다.
- 부정 질문의 근거 없는 주장 승인0건, 긍정 질문 과도 거절률≤10%. 거리 하나로 진실 여부를 결정하지 않는다. 아직 답변/보류 판정기가 없으므로 벡터 순위만 실행해 이 항목을 통과시킬 수 없다.
- ID 집합1,000개 일치·중복0·누락0·norm 오차≤1e-5. 근사검색과 동일 벡터 정확검색의 Recall@10≥0.99는 의미 검색 정답 점수와 별도다.
- 언어별 보류 긍정은15개이므로 점수 변화가 크다. 표본 수·개별 오류·불확실성을 함께 보고하며 일반 검색 품질의 확정으로 확대하지 않는다.
- CPU 첫 실행/반복 지연·p50/p95·메모리·디스크를 측정한다. 운영 응답 SLA 수치는 아직 고정하지 않아 성능 합격이라고 판정하지 않는다.

## 파일 관계와 안전 경계

source-graph.json → source-id-ledger.json / candidates.json → 문서A/C → 향후 별도 실험.
questions-draft.json → review-sheet.csv 검수 → 새 버전 정답 고정 → 실험 허용 여부 판단.
model-lock.json + library-lock.json → 별도 offline 실행 환경 고정 → 환경 점검.
pilot-spec.json → 기준 / 금지 범위. manifest.sha256.json → 준비 파일 내용 고정.

실제 runner·Chroma 저장 디렉터리·벡터는 아직 없다. 준비 폴더는 별도 경로일 뿐 OS 수준 sandbox를 구현했다는 뜻이 아니다. 다음 실행 시 원본/운영 볼륨·인증정보를 연결하지 않고 네트워크를 차단한 일회용 환경임을 확인한다. 기존 DB 경로·기존 컬렉션 재사용은 거부하고 migration/큐 재생 오류 시 해당 실험 공간에서 중단한다. 전량40,664개 색인과 운영 전환은 허용하지 않는다.
