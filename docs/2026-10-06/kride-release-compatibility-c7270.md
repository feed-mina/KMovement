## 1. 원본·압축·후보 모델 고정

## 2. 128쌍 수치 비교 · 통과

같은 저장 사건의 기존 문서/벡터 128쌍에 원문·공백·대소문자·접두사를 추가하지 않고 후보 모델을 적용했다. 차원 384, float32, 전부 유한 값. 최대 norm 오차 1.192092896e-07, cosine 중앙 1, 최소 0.9999998808, 성분 최대 절대 차이 1.37835741e-07. 사전 기준 norm≤1e-5·중앙 cosine≥0.9999·최소≥0.999를 통과했다.

해석: 이 후보는 보존된 큐 표본에서 기존 벡터와 수치상 일치한다. 전체 44,560개 색인의 모델 생성 provenance나 전체 HNSW 무결성까지 증명하지 않는다. 표본은 무작위·대표 표본이 아니며 PDF 32쌍은 fingerprint만 검증했다.

## 3. 고정 벡터 질문 A/B · 영어·일본어 미달

## 4. 격리 복사본 전체 검색 · 사전 검사 실패로 중단

압축을 안전한 경로의 일회용 작업 폴더에만 풀었다. 원본·운영 볼륨을 쓰기 가능하게 연결하지 않았다. SQLite 3.53.1의 integrity_check 결과는 `malformed inverted index for FTS5 table main.embedding_fulltext_search`이고 foreign_key_check는 10건이다. 원본 디렉터리와 압축 복사본 54개 파일이 바이트 단위로 같다는 확인과 SQLite 검사의 실패는 서로 다른 판정이다.

이 사전 검사가 통과하지 않아 Chroma 클라이언트 생성과 전체 검색을 실행하지 않았다. migration·큐 재생·repair·복원·재색인도 하지 않았으며 복사본 추가/삭제/수정 파일은 모두 0개다. 이 오류가 저장 색인 손상인지 생성 당시 SQLite/Chroma 버전과의 호환성 문제인지 아직 확정하지 않는다. 원본 전체 검색은 정상이라고 보고하지 않는다. 다음 조사는 원본을 지키는 별도 버전 비교·원인 분석이며 운영 복원과 분리해야 한다.
