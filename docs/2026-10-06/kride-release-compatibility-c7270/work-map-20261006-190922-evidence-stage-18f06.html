# 근거·검증 방법 확인 — 실제 실험은 별도 단계 확인 시점: 2026-10-06T19:09:22+09:00. 이번 작업은 근거 파일·프로토콜의 대조와 파일 해시 확인뿐이다. 원본 DB를 Chroma 클라이언트로 열지 않았고 모델 로드·추론·검색 실험·복원·재색인·운영 호출을 하지 않았다. ## 확인 완료 - 원본 DB, 전체 압축 백업, PDF 백업, 원본 그래프와 MLflow DB를 포함한 7개 파일은 이번 읽기 전후 해시가 같고 이전 조사 해시와도 같다. 세 소스 파일도 확인 중 해시가 같았다. DB 해시 확인은 전체 색인의 검색 가능성 검증을 뜻하지 않는다. - 두 MLflow FINISHED 실험은 각 장소 10개, E5-small·384차원·cosine을 기록한다. 실험 이름의 Qwen/Groq 답변 모델과 임베딩 모델은 구분한다. 전체 44,560개 색인과 연결된 생성 run/revision은 미확정이다. - 기존 큐 표본 128개는 같은 저장 사건의 원문이 존재하고 현재 저장 문서와도 일치한다. 표본은 각 비어 있지 않은 컬렉션에서 32개씩이다. 큐에 남은 표본이므로 전체 색인의 무작위·대표 표본으로 보지 않는다. - 예전 장소 40,664개는 기록된 builder 형식과 일치하며 PDF 포함 문서 44,560개에 query:/passage: 접두사가 없다. 현재 저장소 소스는 문서 passage: / 질문 query: 및 e5-prefix-v1을 사용한다. 현재 운영 배포와 동일한지는 이번에 접속해 검증하지 않았다. ## 검증 방법 확인 · 제안만 1. 원본·압축·설정의 해시 및 후보 모델 revision을 고정한다. 원본 sidecar/WAL·색인 파일 목록과 완전성을 읽기 전용으로 확인한다. 파일이 계속 쓰이는 상태라면 단순 파일 복사를 완전한 스냅샷으로 간주하지 않는다. 가중치·tokenizer·config·라이브러리 버전은 별도 실행 준비 기록으로 남긴다. 2. 같은 저장 사건의 원문·벡터 128쌍을 후보 모델로 수치 비교한다. 원문과 공백·접두사·대소문자를 그대로 보존한다. 제안 기준은 차원384·유한 float32·norm 오차≤1e-5, cosine 중앙값≥0.9999·최솟값≥0.999다. 실행 전 고정할 제안값이며 이번 통과 결과가 아니다. 통과해도 전체 생성 모델의 역사적 증명은 아니다. 3. 저장 벡터를 고정한 채 원문 질문/query: 질문을 A/B 비교한다. 문서 형식과 질문 형식을 동시에 바꾸지 않는다. 한국어12·영어12·일본어12·근거없음4, 검토된 정답 ID와 baseline, Recall@5/nDCG@10 품질 목표를 준비한다. 정답·절대 목표는 아직 미준비다. 표본 결과를 전체 검색으로 확대하지 않는다. 4. 전체 검색은 완전한 격리 복사본에서만 수행한다. 원본·운영 볼륨과 인증정보를 연결하지 않는다. Chroma 클라이언트의 migration/큐 재생은 복사본에서도 기록하고 실패 시 해당 복사본에서 중단한다. 원본 복원·재색인은 이번 제안 범위에 포함하지 않는다. 5. 수치 표본 / 전체 검색 / 공개 API·출처 계약을 별도로 판정한다. 계약명만 붙여 guard를 통과시키지 않는다. 출처 URL, 좌표, 지역, 예산·아티스트 연결과 근거없음 처리는 벡터 일치와 별도 검증이다. ## 단계 경계 지금 완료된 것은 근거와 검증 설계 확인이다. 모델 추론·질문 A/B·전체 복사본 조회는 모두 별도 실행 단계이며 자동으로 시작하지 않는다. 사용자가 지금 터미널에서 수행할 작업은 없다. 실행 단계에서는 준비 자료와 기준을 먼저 고정하고, 원본 보존 결과·버전 manifest·측정 결과·실패 내역을 받아야 한다. 이번에는 운영 서버에 접속하지 않았다. 따라서 운영에 대한 보존 범위는 이 작업이 운영 요청/변경을 수행하지 않았다는 사실이며 다른 작업에 의한 운영 변경이 없었다고 주장하지 않는다. 기존 HTML·MD·프로토콜을 덮어쓰지 않았다. 근거 시점: 모델 기록 2026-10-06T18:50:48+09:00, 텍스트 검사 2026-10-06T18:54:00+09:00. 상세 해시·근거 목록은 confirmation.json. 기존 계획: ../20261006-185838-embedding-compatibility-4953e/README.md 및 protocol.json.
