# 내비게이션·지도 겹침 수정과 코스 화면 모션

## 문제와 변경

첨부 화면에서 더보기 메뉴가 지도 내부 레이어에 가려졌고, 지도 확대·축소와 Kakao·Google 선택 버튼이 왼쪽 위에서 겹쳤다.

- `.route-map`과 지도 본체에 별도의 쌓임 맥락(`isolation: isolate`, `z-index: 0`)을 설정했다. 내비게이션의 기존 표시 순서 60을 유지하면서 지도 내부의 높은 표시 순서가 페이지 밖으로 나오지 않도록 했다.
- Kakao·Google 선택 버튼을 지도 안의 절대 위치에서 지도 위의 독립 도구줄로 옮겼다. 선택 버튼의 `aria-pressed`와 제공자 저장을 유지했다.
- 지도 대체 안내를 일반 문서 흐름으로 옮겨 지도 출처를 덮지 않게 했다. 대체 지도는 OpenStreetMap 사용 상태를 도구줄에 표시한다.
- 코스 화면의 중복 지도 래퍼 클래스를 제거했다.
- 더보기는 바깥 누름, Escape, 메뉴 항목 선택, 페이지 변경 때 닫힌다. Escape는 더보기 버튼으로 초점을 돌린다.

## 모션과 조작

| 대상 | 변경 동작 |
|---|---|
| 더보기 | 150ms 투명도·4px 등장, 동작 줄이기에서는 제거 |
| 지도 제공자 버튼 | 선택 표시 이동, 호버·누름·리플 |
| 요약 카드 | 200ms 등장 |
| 일정 목록 | 처음 6개 항목에 최대 200ms의 순차 등장 지연 |
| 일정 장소명 | 키보드로 조작 가능한 지도 선택 버튼 |
| Leaflet 핀 | 클릭 선택을 목록에 전달, 선택한 내부 원만 한 번 확대. 바깥 좌표 변환은 유지 |
| Leaflet 카메라 | 기존 1.5초 이동을 0.5초로 조정, 동작 줄이기는 즉시 이동 |
| Kakao·Google | 선택한 핀 우선순위와 정보창 유지, 동작 줄이기에서 pan 대신 중심 설정 |
| 공유 | 실제 복사 성공 후에만 짧은 상태 안내. 공유창 취소를 성공으로 표시하지 않음 |

지도 전체나 SDK가 위치를 계산하는 바깥 요소에는 틸트를 적용하지 않는다. 네이티브 Kakao·Google 마커에 Leaflet 내부 원의 확대 효과를 적용했다고 계산하지 않는다.

## 변경 파일

웹 경로는 `subproject/SDUI/metadata-project/` 기준이다.

- `app/styles/common.css`: 지도 레이어 격리·도구줄·지도 높이·대체 안내.
- `app/styles/kride-unified.css`: 더보기 표시 순서·크기 제한·등장.
- `app/styles/route-screen.css`: 요약·목록·선택 핀·하단 액션 반응.
- `app/styles/kride-motion.css`: 공유 결과 안내.
- `components/layout/KrideNav.tsx`: 메뉴 닫기와 초점 복원.
- `components/fields/kride/maps/RouteMap.tsx`: 지도 선택 도구줄 및 장소 선택 전달.
- `components/fields/kride/maps/LeafletFallbackMap.tsx`: 대체 지도 선택 전달.
- `components/fields/kride/MapViewInner.tsx`: Leaflet 핀 선택·카메라·내부 원 강조.
- `components/fields/kride/maps/KakaoRouteMap.tsx`, `GoogleRouteMap.tsx`: 비동기 지도 준비 후 선택 적용·동작 줄이기·대체 지도 선택 유지.
- `components/plugins/travel/RouteScreen.tsx`: 코스 목록과 지도 선택 연결.
- `components/fields/kride/KakaoShareButton.tsx`: 성공한 복사에만 상태 안내.

## 실제 시험 결과

- 관련 Jest 10개 묶음, **89개 통과**. 기존 탐색 시험도 포함한다.
- 메뉴 닫기·초점 복원, 지도 제공자 상태 보관, 목록 이벤트와 지도 콜백, Leaflet 내부 원 선택, 좌표 변환 유지, 동작 줄이기 카메라, 복사 성공 시점 등을 모의 환경에서 확인했다.
- TypeScript 검사, 수정 소스 ESLint 검사, Next.js 프로덕션 빌드 통과.
- 이 결과는 jsdom 및 모의 지도 객체를 사용한 검사다. 실제 브라우저의 그리기 순서, 지도 타일·네이티브 SDK·모바일 터치 시험을 대신하지 않는다.

## 배포 상태와 남은 확인

이번 작업 중 Hostinger 운영 서버는 교체하지 않았다. 브라우저 확장 연결은 사용할 수 없었고, 기존 클라우드 브라우저의 Hostinger 로그인 접근 제한이 남아 있다. 이미지 게시 성공이나 운영 반영 완료로 기록하지 않는다.

main 반영 후에는 [배포·복구 가이드](../../operations/hostinger-main-deploy.md)를 따른다. 이 문서는 해당 단계의 완료를 뜻하지 않는다.

운영 반영 뒤 확인할 항목:

1. 데스크톱에서 더보기를 펼친 상태로 지도 타일·핀·팝업이 메뉴를 덮지 않는지 확인.
2. 390px 모바일 폭에서 하단 내비게이션·더보기·하단 액션 바가 지도보다 위에 표시되고 출처가 보이는지 확인.
3. Kakao·Google 선택 버튼과 확대·축소가 각자 공간에 표시되는지 확인.
4. 목록에서 장소 선택 → 지도 강조, 지도 핀 선택 → 목록 강조가 연결되는지 확인.
5. 동작 줄이기 설정 전환 시 카메라·핀·메뉴가 줄어드는지 확인.
6. 공유 링크 복사가 실패했거나 취소된 경우 완료 안내가 나오지 않는지 확인.
7. 로그인·기본 코스·명시적 동의·오류 안내가 기존과 동일한지 확인.

운영 DB·사용자 동의·AI 생성 요청 계약은 변경하지 않았다. 시험을 위해 실제 사용자 동의를 자동 체크하거나 유료 생성 요청을 실행하지 않았다.
