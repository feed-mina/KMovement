## 원본 자료에서 이미 보이는 문제

- 알베르: 주소는 강남대로102길(강남)인데 좌표 37.682, 126.792는 서울 북서쪽(고양 부근)입니다. 좌표 오류.
- 럭키스트라이크볼링센터: "1집 타이틀곡 예쁘다"라고 적혀 있으나 '예쁘다'는 미니 2집(BOYS BE) 타이틀입니다. 설명 오류 가능.
- GRC서킷·두리캠핑장: 둘 다 "고잉 세븐틴 21화"로 적혀 있습니다. 최소 하나는 회차가 틀렸을 수 있습니다.
- 동작대교 "CALL CALL CALL!": 일본 데뷔 싱글 MV입니다. 국내 촬영 여부부터 확인이 필요합니다.
- URBAN81 영업시간: 원본은 "평일 8:30–21시, 토 12–20시, 일 휴무"였으나 2026-11-10 운영자 정보는 평일 8:30–19:30, 주말 휴무.
  → 원본 영업시간은 모두 2023년 값이라 그대로 쓰지 않습니다.

## 한 곳 검수 절차 (URBAN81과 같은 기준)

1. 공식 근거: 공식 채널 영상/공지에서 멤버·장면·시각(locator) 확인. 팬 재업로드는 보조 근거로만.
2. 장소 동일성: 화면 속 장소 = 현재 tour_poi 행(이름·주소·좌표)인지. 상호 변경·폐업 확인.
3. 현재 조건: 운영자 등록 정보로 영업시간·1인 최소 방문비·확인일.
4. 운영 DB에는 PENDING으로 넣고, VERIFIED 전환은 민아님 확인 후.
