# 코스 조건 화면과 로그인 진입 개선

AI 코스 입력을 날짜·언어, 1인 방문비, 선택 동의, 선택 내용·생성 버튼으로 구분한다. 비로그인 상태의 생성 버튼은 날짜 미입력이나 지원 밖 선택으로 막지 않고 기존 로그인 화면으로 이동한다. 로그인 상태 확인 중과 생성 중에는 중복 동작을 막는다.

로그인 직전에 같은 탭의 sessionStorage에 입력값만 10분 보관한다. 신원·인증 토큰·생성 결과는 저장하지 않는다. 돌아오면 허용된 값인지 검사한 뒤 한 번 복원한다. 복원만으로 추천 요청을 보내지 않으며 선택 동의를 자동으로 켜지 않는다. 기존 returnTo 검증과 서버의 인증·조건·권한 검사는 유지한다.

AI 코스 설정 중에는 결과용 길찾기·공유 바를 표시하지 않아 입력 영역이 가려지지 않는다. 기존 기본 코스와 생성된 AI 코스의 결과 기능은 유지한다. 공통 입력 최소 높이는 checkbox/radio를 제외하며 이 화면의 동의 체크박스는 21px로 표시한다.

## 검증

- TypeScript 검사 통과.
- RouteScreen, 기존 로그인 복귀, 입력 초안 만료·유효성 검사 3개 테스트 묶음 45개 통과.
- Next.js 운영용 빌드 통과. 검증 빌드는 BACKEND_URL·NEXT_PUBLIC_BACKEND_URL·AUTH_BACKEND_URL·FASTAPI_URL·NEXT_PUBLIC_SITE_URL을 로컬 주소로 지정해 기존 외부 서버 조회를 하지 않았다.
- 실제 RouteScreen을 사용하는 로컬 Chromium 화면에서 비로그인 로그인 버튼, 초안 저장, 1280/420px 가로 넘침 0, 체크박스 높이 21px, 페이지 오류 0 확인. 지도·인증·장소 API는 시험 응답으로 대체했으며 운영 실계정의 추천 성공을 주장하지 않는다.
- 운영은 기존 main CI → Hostinger 웹 독립 배포 경로로 반영한다. 최종 배포 SHA·공개 버전 일치는 별도로 확인한다.
