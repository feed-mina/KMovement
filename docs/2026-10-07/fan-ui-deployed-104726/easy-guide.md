# 좋아하는 아티스트가 먼저 보이도록 바꿨어요
목표: 사진과 이름을 보고, 좋아하는 아티스트를 내 목록에 담는 방법을 쉽게 찾습니다.

1. 흐리던 이름을 진하게, 사진과 소개를 나란히 바꿨어요.
2. 실제 사진 33개에 출처를 붙였고, 로그인 전에도 저장 방법을 알 수 있어요.
3. 새 화면을 서비스에 반영하고 컴퓨터·휴대전화 화면을 확인했어요.

## 이렇게 사용하세요
아티스트 선택 → 사진과 소개 보기 → 내 아티스트로 저장 → 로그인 안내가 나오면 로그인 → 돌아와 저장.
소식·일정과 관련 상품을 나누어 볼 수 있고, 상세를 열었다가 아티스트로 돌아올 수 있어요.
사진 아래 ‘사진 출처’를 누르면 촬영 자료와 사용 조건을 볼 수 있어요.

## 달라진 점
| 이전 | 지금 |
|---|---|
| 흰 글자 때문에 이름이 안 보임 | 진한 이름과 읽기 쉬운 설명 |
| 큰 이니셜만 표시 | 실제 사진. 준비 중이면 이름과 안내 |
| 여행 동선 위주의 단정적인 설명 | 좋아하는 마음과 다음 소식을 찾는 안내 |
| 로그인 전 저장 방법을 모름 | 저장 버튼과 로그인 후 돌아오기 |
| 일정이 없는지 오류인지 구분 어려움 | 일정 없음과 불러오기 실패를 따로 안내 |

## 확인한 범위
자동 동작 검사 59개가 통과했고, 실제 서비스의 여러 컴퓨터 크기와 휴대전화 폭에서 화면을 확인했어요. 사진 33개를 연결했고, 나머지 15개 공개 항목은 사진 준비 상태예요.
실제 로그인 계정으로 저장하는 마지막 행동과 팬들의 만족도 조사는 아직 확인하지 않았어요. 사진은 공개 자료이므로 현재 활동 모습과 다를 수 있어요.

## 지금 직접 할 일
터미널 명령은 필요 없어요. 아티스트 화면에서 사진과 글의 느낌을 살펴보면 됩니다. 바꾸고 싶은 사진은 출처와 사용 범위가 확인된 자료로 알려주세요.
다음 요청문: “새 화면에서 팬들이 이름과 저장 방법을 쉽게 찾는지 확인하고, 대표사진과 소개 문구의 개선점을 정리해줘.”
