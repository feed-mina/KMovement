# 독립 검수 근거와 운영 전환 조건

## 검수 경계
코드 작성자와 분리한 세 AI 에이전트가 역할별로 검토했다. 새 holdout 원문·정답·개별 사례는 비공개 보관하고 작성자에게 집계와 해시만 전달했다. 동일 머신의 폴더 분리는 절차적 분리이며 OS 강제 격리가 아니다. 비공개 질문과 상세 중첩표는 공개 저장소에 포함하지 않는다.

## 장소 출처 계약
공식 시설 ID·명칭·주소·게시 좌표를 확인했다. 출처 범위 승인 17/20, 보완 3/20. 게시 좌표 확인은 실제 출입구 측량이나 현장 확인이 아니다. 가격·아티스트 연결 근거는 미확인이므로 지원한다고 주장하지 않는다.

- N서울타워: 시설 전체와 운영 시설 범위, 일본어 할인 상품 출처의 범위 보완 필요.
- 청계천박물관: 공식 이름·주소 관찰과 전체 HTML 스냅샷 확보를 구분. 발췌 해시는 전체 원문 해시가 아니다.
- 북촌문화센터: 넓은 북촌 소개에서 이름이 나오는 것만으로 정확한 시설·주소 대응을 승인하지 않음.

제안 카탈로그 SHA256: `aca608a8cae40db351625a6084eafebbdcb55503eba235bcfcde1f7dec81e10a`.
장소 검수 결과 SHA256: `9d76f60702f0edce797d22d19913809bd852d612faa93c3642a98e7327ee0aa4`.

## 시험 검수 및 누출 한계
현재 초안은 언어별 양성30·미지원10, 총120문항이다. 40개 번역 묶음이므로 120개의 통계적으로 독립된 관측이라고 하지 않는다. 내부 일관성은 두 차례 검토 후 통과했다. 출처 보류 항목과 의미·장소 중첩 때문에 전체 gold 승인과 동결은 보류한다.

별도 장소 검수자는 새 질문·정답·과거 성적을 읽지 않고 옛 120문항 전체 문맥과 대상 메타데이터를 대조했다. 현재20 중 동일 개체4, 출처 승인17 중 동일 개체3을 확인했다. 관련 시설군3을 추가 제외하는 보수적 제안은 11곳이다. 관련 시설과 동일 시설을 혼동하지 않는다. 기존20 및 17/3 판정과 시험 분모는 바꾸지 않았다. 결과는 제공된 유한120개에 한정하며 모든 역사적 노출이나 모델 학습 데이터의 비오염 증명이 아니다.

질문 SHA256: `d190727f2126f8b0bbcf60f9190b95e3b71a79cdcb76581202bf84455d34c778`.
정답 SHA256: `6365fd12745280badc6ee1cb83c18b24d32fdc33e190c2c3b631ad1ba5226d95`.
이 해시는 보존된 초안 식별자이며 통과한 시험 인증이 아니다.

## 이미지·모델 준비
병합 commit `92e3d271a3aa4199a03c5fb668249963a43ecb25`의 웹·CPU 이미지 발행 완료. CPU 산출물의 검사115개는 실패·오류·건너뜀0이다. image-preparation.json에 정확한 digest를 기록했다. 이것은 실제 검색·LLM·로그인 검사와 별개다.

multilingual-e5-small revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`의 준비 모델 파일10개 실제 SHA256이 기존 고정 목록과 일치했다. 읽기 전용 확인이며 모델 추론은 실행하지 않았다. 새 실행 환경의 전체 의존성 해시·입출력 manifest·리소스 여유·컨테이너 제한은 실행 직전 다시 검증해야 한다.
