2. 중복처럼 보이는 곳을 나눴습니다

같은 이름·주소인 3,313묶음 중 좌표가 사실상 같은 것은 214묶음, 서로 다른 좌표가 100m 안에 모인 것은 2,798묶음, 100m 넘게 벌어진 것은 301묶음입니다. 가까워도 다른 시설일 수 있어 자동으로 합치거나 삭제하지 않았습니다. 301묶음부터 위치를 다시 확인할 수 있습니다.

3. 공식 자료와 1,709개 기록을 연결했습니다

공공데이터포털의 공식 촬영지 자료 15,034행과 대조했습니다. 기존 장소 1,709개가 이름·주소로 일치했고, 그중 1,667개는 대응 자료의 좌표가 모두 100m 이내입니다. 42개는 좌표 검토가 필요합니다. 촬영지 자료에 있다는 사실만으로 현재 영업, 특정 아이돌 방문, 무료 입장을 보장하지 않습니다.

4. 다국어 이름은 확인된 4곳부터

이전에 독립 검수한 공식 자료의 파일이 바뀌지 않았는지 확인한 뒤, 대한민국역사박물관·국립현대미술관 서울·서울공예박물관·전쟁기념관의 한국어·영어·일본어 이름을 기존 5개 기록에 연결했고, 별도 AI 검수자가 이번 연결의 동일 시설 여부도 승인했습니다. 현장 방문 검증은 아닙니다. 박물관 하나가 기존 기록 2개에 해당합니다. 남은 40,659개 기록은 다국어 근거 연결이 미완료입니다. 임의 번역을 공식 이름으로 넣지 않았습니다.

5. 주소와 좌표는 별도 보완 목록으로

주소가 없는 1,382개, 국내 범위 밖 좌표 202개, 공식 자료와 좌표 검토가 필요한 42개를 분리했습니다. 서로 겹치는 대상을 제외하면 1,472개 기록입니다. 국내 범위 밖이라는 이유만으로 잘못된 장소로 판단하지 않습니다. 확인 가능한 공식 값은 비교 자료로 보관하고 원래 주소·좌표는 바꾸지 않았습니다.

6. 다음은 남은 근거 검수입니다

공식 출처를 연결한 기록의 합집합은 1,712개이며, 아직 연결하지 못한 기록은 38,952개입니다. 같은 시설인지 검수하고 위치 차이를 해소한 뒤 공식 이름과 지역을 더 연결해야 합니다. 가격·아티스트 관계는 별도 근거가 필요합니다. 검색 DB 구축·검색 실행·운영 공개는 하지 않았으며 사용자가 터미널을 실행할 일은 없습니다.
