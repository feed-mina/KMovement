# 좋아하는 아티스트의 일정을 더 쉽게 찾아보세요
목표: 내가 좋아하는 아티스트가 언제, 어디서 만나는 일정을 올렸는지 찾아봅니다.

1. 화면 위에서 내 아티스트와 전체 아티스트를 고를 수 있어요.
2. 국내·해외·온라인을 나누고, 해외에서는 나라를 골라요.
3. 새 화면을 서비스에 반영하고 컴퓨터·휴대전화 화면을 확인했어요.

## 이렇게 사용하세요
로그인 → 내 아티스트 → 국내 또는 해외 → 나라·날짜 선택 → 일정 상세·공식 안내 확인.
로그인하지 않았다면 전체 아티스트에서 이름으로 찾아볼 수 있어요. 내 아티스트가 비어 있다면 먼저 좋아하는 아티스트를 저장하세요.

## 이전과 지금
| 이전 | 지금 |
|---|---|
| 날짜 설명과 지역 직접 입력이 먼저 | 좋아하는 아티스트와 국내·해외 선택이 먼저 |
| 긴 전체 목록 | 조건에 맞는 전체 건수와 12개씩 보기 |
| 관심 일정만 찾기 어려움 | 로그인한 내 관심 아티스트만 모아보기 |
| 상세 뒤 조건을 다시 선택 | 선택 조건을 유지해 목록으로 돌아오기 |
| 일정이 없는지 오류인지 모호 | 일정 없음과 조회 실패를 따로 안내 |

## 확인한 것과 아직 모르는 것
공개 목록 90건의 페이지 이동과 국내·해외·온라인 선택, 컴퓨터·휴대전화 배치를 확인했어요. 로그인하지 않고 개인 목록을 보는 것은 막혀 있어요.
실제 로그인 계정으로 저장하는 마지막 동작과 팬 만족도 조사는 아직 확인하지 않았어요.

나라와 날짜는 현재 등록된 자료를 보여줘요. 공식 공지를 새로 모두 확인한 것은 아니에요. 정확한 공연 시간·변경·취소는 공식 안내에서 확인해 주세요. 모르는 위치는 ‘위치 미확인’으로 남겨요.

## 지금 직접 할 일
터미널 명령은 필요 없어요. 내 아티스트와 해외 나라를 골라 원하는 일정이 잘 찾아지는지 보세요.
원하면 다음처럼 요청할 수 있어요. “실제 로그인 계정에서 내 관심 일정과 저장 기능을 확인하고, 공연 날짜·시간의 공식 근거를 더 보강해줘.”
