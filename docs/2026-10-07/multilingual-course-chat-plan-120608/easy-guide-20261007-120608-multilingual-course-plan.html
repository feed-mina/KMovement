목표: 코스를 만든 뒤 그 아래에서 한국어·영어·일본어로 같은 여행 코스에 질문할 수 있게 합니다.

  1. 앞선 1,000개 장소 시험은 영어·일본어와 출처 확인에서 아직 통과하지 못했습니다.
  2. 우선 서울 장소 20개를 꼼꼼히 준비하는 방법을 제안합니다. 확인 절차를 빼지는 않습니다.
  3. 새 시험과 실제 로그인 검사를 통과한 버전만 공개하고, 문제가 생기면 이전 버전으로 돌아갑니다.

지금 어디까지 왔나요?

전체 과정은 ‘장소 준비 → 세 언어 확인 → 코스와 대화 연결 → 시험 후 공개’입니다. 지금은 장소 준비 방법을 정리한 단계입니다. 이번에 공식 이름 자료 2건을 찾았지만, 모든 조건을 확인한 새 장소는 아직 0개입니다. 새 시험·프로그램 수정·배포는 하지 않았습니다.

다음 행동 하나: 서울 장소 20개의 이름과 지도 위치, 공식 안내를 하나씩 대조합니다.

아직 모르는 것: 외국어 이름을 제대로 연결하면 검색이 얼마나 좋아질까요? 확인하는 방법: 연습 문제로 고친 뒤, 미리 보지 않은 새 시험에서 세 언어를 따로 검사합니다.

영어·일본어로 서울을 안내하는 기능입니다. 해외 여행까지 지원한다는 뜻은 아닙니다. 20개를 다 준비하지 못하면 부족한 점을 먼저 알립니다. 시험에서 틀린 장소만 빼서 합격처럼 만들지 않습니다.

2. 이름이 달라도 같은 장소를 가리켜야 해요

앞선 개발 문제에서는 동궁과 월지·성산일출봉·해운대·어니언 성수·곰솔마루·창덕궁 질문에 다른 장소가 나왔습니다. 비슷한 종류의 장소를 찾았어도 원하는 장소가 아니면 틀린 답입니다. 외국어 이름 연결이 부족했을 가능성은 있지만, 아직 원인 전부를 증명한 것은 아닙니다.

창덕궁과 후원은 한국관광공사 영어 안내와 일본어 안내에서 이름을 확인할 수 있습니다. 서울역사박물관 일본어 소개도 찾았습니다. 이름 자료를 찾았다고 가격·예약·지도 위치까지 모두 확인된 것은 아닙니다. 궁궐과 후원의 관람 조건도 구분해야 합니다.

도우미가 할 일: 같은 장소의 세 언어 이름과 공식 안내를 연결하고, 지점이 다른 곳이나 비슷한 이름을 구별합니다. 사람이 확인하기 전까지 새 공개 장소로 표시하지 않습니다.

3. 코스 다음 화면은 이렇게 바뀌면 좋아요

코스 만들기 → 장소 카드와 지도 보기 → 화면 아래 ‘이 코스에 질문하기’ → 한국어 / English / 日本語 선택 → 같은 코스에 대한 답변과 공식 안내 보기.

언어를 바꿔도 지도 위치와 장소 순서는 그대로입니다. ‘두 번째 장소를 설명해 줘’라고 물으면 지금 코스의 두 번째 장소를 설명합니다. ‘장소를 바꿔 줘’는 변경안을 먼저 보여줍니다. 단순히 물어봤다고 코스를 마음대로 바꾸지 않습니다.

가격을 모르면 ‘가격 미확인’, 아티스트와의 관계를 모르면 ‘아티스트 관련 정보 미확인’이라고 보여줍니다. 해당 조건이 꼭 필요하면 지원하지 못함을 알리고 일반 코스로 바꿀지 선택하게 합니다. 알려줄 수 있는 장소 설명까지 전부 거절하지 않는지도 검사합니다.

4. 답을 보면서 같은 시험을 고치지 않아요

연습 문제에서 개선한 다음, 만든 사람과 분리된 언어 검토자가 정답을 확인합니다. 새 시험은 120문제를 제안합니다. 각 언어에 답할 수 있는 질문 30개, 근거가 없거나 지원하지 않는 질문 10개를 둡니다.

시험 결과를 보고 고쳤다면 새 시험으로 다시 확인합니다. 이미 본 시험에서 점수만 올린 것을 새 실력처럼 말하지 않습니다. 20개 장소의 좋은 점수가 옛 1,000개 장소 전체가 좋아졌다는 뜻도 아닙니다.

지금 필요한 것: 독립 언어 검토자와 새 정답 검수. 아직 완료하지 않았습니다. 사용자에게 터미널 명령이나 이미 끝낸 로그인 준비를 다시 요구하는 단계는 아닙니다.

5. 공개 전에 확인할 것

  • 세 언어에서 원하는 장소를 찾는지 각각 검사합니다.
  • 일정 카드·지도·대화·공식 안내가 같은 장소를 가리키는지 확인합니다.
  • 모르는 사실을 만들지 않고, 아는 내용까지 불필요하게 거절하지 않는지 확인합니다.
  • 실제 로그인 후 첫 답이 오는 시간, 중단·종료·재시도와 계정 전환을 확인합니다.
  • 하루 합산 최대 1달러·사용자당 10회·동시 2건 제한을 유지합니다. 실제 답변 검사는 필요하면 여러 날 나눕니다.
  • 통과한 버전과 이전 버전을 함께 보관하고, 문제가 있으면 이전 상태로 돌아갑니다.

속도 목표는 아직 확정 전 제안입니다. 첫 실제 답변의 대부분이 10초 안에 시작되고 코스는 30초 안에 완성되는지 검사하는 안입니다. 기존 검색 속도만 보고 대화가 빠르다고 판단하지 않습니다. 일부 조건이라도 검사하지 못하면 공개 완료라고 하지 않습니다.

내가 할 일과 맡길 일

지금 직접 할 일: 터미널 작업 없음. ‘서울 20개부터 세 언어로 안내하고, 근거 없는 팬 장소·가격은 약속하지 않는다’는 출시 범위를 검토하면 됩니다.

도우미에게 부탁할 말: “서울 장소 20개의 세 언어 이름과 공식 근거를 준비해줘. 모르는 가격·아티스트 정보는 분명히 적고, 새 시험은 연습과 분리해줘. 코스 아래 대화가 같은 지도와 출처를 이어받도록 설계하고, 통과한 검사와 남은 검사를 구분해서 보여줘.”

끝났는지 확인하는 법: 장소별 확인표, 새 시험 결과, 실제 로그인 화면, 중단·재시도 결과, 이전 버전으로 돌아가는 방법을 받습니다. 이번에는 이 방법을 담은 보고서까지 만들었습니다. 실제 공개는 아직입니다.
