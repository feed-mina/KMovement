# 독립 검수 인계

현재 후보 20개는 출처 탐색을 완료한 초안이다. 검수 통과 기록이 아니며 공개 적격은 0개다.

1. 후보 ID·선정 사유를 유지하면서 장소 범위/분관/건물과 이름을 ko/en/ja로 대조한다. 공백·괄호 변경과 별칭은 근거를 기록한다. 오래된 명칭 자료는 현재 장소 동일성을 별도 확인한다.
2. 좌표·주소·지역을 각 공식 자료와 대조하고 모호하면 반려한다. 이름이 발견됐다는 사실만으로 동일 장소를 인정하지 않는다. 청계천 이름 자료는 전체 HTML 해시가 아닌 관찰 발췌 해시다.
3. 이름·좌표·지역만 검토 대상으로 삼고 가격·아티스트 연관은 unknown으로 유지한다. 출처의 개수와 주장별 근거 충족은 다르다.
4. 검수 후 변경이 있으면 새 파일과 해시를 만든다. 정확한 최종 파일 해시와 작성자와 다른 검수자 식별자를 승인 기록에 연결한다. 현재 pending 값을 코드 작성자가 일괄 verified로 바꾸지 않는다.
5. 개발 질문 실패 유형은 표기/별칭, 장소 단위 혼동, 지역, 근거 부족, 과거절로 분류한다. 개발 세트와 새 시험은 분리한다. 검수자는 새 시험 120개의 언어별 정답 ID·허용 대답·거절 기대를 준비한다. 시험 원문은 구현 담당과 분리해 보관한다.
6. 품질 목표와 분모, 코드·모델·라이브러리·후보·문서·질문 해시를 평가 전에 동결한다. 고정 벡터 query 접두사 A/B와 문서 형식 C, 이름 매칭 변경은 별도 실험으로 기록한다.
7. holdout 공개 뒤 수정하면 같은 시험으로 통과를 주장하지 않는다. 검색, 출처 계약, 근거없음 및 양성 과거절, 시간·자원, 실제 로그인 수용은 별도 판정한다.

별도 검수 담당 선택은 대화에서 요청한 답변을 기다리고 있다. 실행 허용·배포 판정은 아직 false다. 독립 검수의 수단을 확정해야 새 정답/시험을 준비할 수 있다.
