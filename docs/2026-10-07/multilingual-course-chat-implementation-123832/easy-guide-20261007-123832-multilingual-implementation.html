준비한 장소와 근거

서울역사박물관·남산골한옥마을·N서울타워 등을 포함한 20개입니다. 이름 60개(20곳×3개 언어)의 공식 표기 자료를 모았습니다. 이름·주소·지도 좌표가 있는 공식 페이지와 외국어 자료를 연결했으며, 독립 검수는 아직입니다. 전체 궁궐 대신 일부 건물만 찾아진 4곳은 시험 전에 다른 장소로 교체해 이유를 남겼습니다.

무엇을 확인했나요?

서버 계약 검사 54개, 프론트 핵심 검사 21개, TypeScript 검사가 통과했습니다. 실제 검색·생성 모델 대신 모의 공급자 등을 사용하는 검사입니다. 새 120문항 시험, 실제 답변 품질, 로그인 화면, 첫 응답 시간, 중단·재시도는 아직 확인하지 않았습니다.

다음 행동

앞서 질문드린 독립 검수 담당 선택을 기다리고 있습니다. 별도 검수 에이전트로 진행할지, 지정 검수자가 있는지 정해지면 새 정답과 시험을 작성자와 분리해 준비합니다. 사용자에게 터미널 작업을 요청하지 않습니다.

검수가 끝나면 설정을 고정하고 새 시험을 치릅니다. 실패 후 수정하면 새 시험이 필요합니다. 검색·출처·거절·속도·로그인 검사까지 통과한 버전만 배포합니다. 하루 합산 1달러·사용자당 10회·동시 2건 제한 때문에 실제 생성 검사는 여러 날에 걸칠 수 있습니다.

원본 DB와 기존 운영 서비스는 그대로 유지했습니다. 같은 호스트에서 새 업로드 경로만 읽는 임시 검사 컨테이너를 실행했으며, 운영 DB·모델·인증정보를 연결하지 않았습니다. 기존 운영 데이터나 검색 색인을 수리하거나 재색인한 작업이 아닙니다.
