다음: 후보·명칭·좌표 독립 검수 → 새 질문과 정답 동결 → 모델·라이브러리 해시·경계 확인 → 격리 검색 → 실제 생성·로그인 수용 → 모두 통과한 release만 배포.

운영 유지: 원본 DB·기존 운영 컬렉션·서비스 설정을 변경하지 않았다. 새 파일만 사용하는 임시 계약 검사 컨테이너는 실행했다. 품질 평가·운영 이미지 빌드·배포는 미실행이다.

실패 분기: 검수 반려 시 자료 수정과 새 해시. holdout 실패 후 수정 시 새 시험. 운영 수용 실패 시 이전 exact image/collection/config로 복귀. 현재는 운영 전환 자체가 없어서 rollback을 실행하지 않았다.
