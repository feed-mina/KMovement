# 11곳 시험 고정과 격리 검색 결과

**11곳·51문항을 독립 검수해 고정하고 격리 검색을 실행했습니다. 검색 기준은 통과했으며 운영 전환은 보류합니다.**

## 완료한 일
| 단계 | 확인 결과 |
|---|---|
| 장소 근거 | 11곳 이름·주소·게시 좌표·지역, 공식 원문18개 연결 및 해시 고정 |
| 새 시험 | 한국어·영어·일본어 각 양성11+근거없음6, 총51개·번역군17개 |
| 독립 검수 | 작성자와 분리한 정답 검수 및 검색 실행 코드 검수 완료 |
| 실행 환경 | 정확한 CPU 이미지, 의존성 파일52,697개·모델10개 해시 고정 |
| 격리 검색 | CPU1개·4GB·최대10분·외부 네트워크 차단, 새 임시 컬렉션만 사용 |

새 질문과 정답은 코드 작성자에게 공개하지 않았습니다. 독립 담당이 보관·전송했고 작성자는 집계만 확인했습니다. 기존20곳과120문항은 보존했습니다.

## 검색 결과
| 언어 | 상위5개 안에 정답 포함 | 순위 품질 nDCG@10 | ANN 일치 |
|---|---|---|---|
| 한국어 | 1.000 | 1.000 | 1.000 |
| 영어 | 1.000 | 0.955 | 1.000 |
| 일본어 | 1.000 | 1.000 | 1.000 |

위 표는 질문에 query:를 붙인 B 방식입니다. 붙이지 않은 A와 점수가 같았으며, 공식 이름을 우선하는 P 방식은 세 언어 모두1.000입니다. A/B 동안 저장 벡터는 그대로 유지했습니다. 검색 전체 실행은 약25초, 최대 메모리는 약0.96GiB였습니다.

**작은11곳에서의 결과입니다.** 51개 문항은17개 번역 묶음이며, 서로 독립인51개 실험이 아닙니다. 11곳 중10곳을 찾는 ANN 결과로1000곳·전국 검색 품질을 보장하지 않습니다.

## Before / After — 이번 단계의 변화
| 이전 | 현재 |
|---|---|
| 11곳은 제안 | 출처 승인 파일·카탈로그 해시 고정 |
| 시험120 초안, 미동결 | 새51개를 별도 버전으로 독립 검수·동결 |
| 실제 검색 미실행 | 고정 버전의 격리 검색 통과 |
| 운영 공개 미실행 | 그대로 유지, 실제 응답·로그인 검사는 미완료 |

실제 서비스 화면 비교가 아닌 검증 상태 비교입니다.

## 남은 일과 현재 제약
실제 생성 답변이 근거 없는 가격·아티스트 주장을 거절하는지, 정상 질문을 과도하게 거절하지 않는지 아직 검사하지 않았습니다. 로그인 뒤 첫 응답 시간·중단·재시도도 미검사입니다.

읽기 전용 한도 확인 당시 테스트 계정1개에 오늘10회가 남았습니다. 합산1달러/일·사용자10회/일·동시2건을 유지하므로51개 실제 응답 검사는 최소6일에 나눠야 합니다. 브라우저 연결 도구는 초기화 오류로 두 번 모두 실패해 실제 로그인 화면 검사가 막혀 있습니다. 자동 승인 거절 때문이 아닙니다.

다음은 시험 전용 실제 서비스 경로와 브라우저 검사를 준비하고 한도 내에서 답변 검수를 이어가는 단계입니다. 자동 일정이나 반복 실행은 생성하지 않았습니다. 사용자가 터미널을 다시 실행할 필요는 없습니다.

원본DB·기존컬렉션·운영이미지는 변경하지 않았습니다. 실행 컨테이너의 새 컬렉션은 임시 출력에만 만들었고 종료 후 운영에 연결하지 않았습니다.
