2. 자동 통과

공개 준비 자료 요건 통과는 1,652개 기록이며, 이미 동일 장소로 검수된 중복 연결만 묶으면 1,651개 후보입니다. 이 수는 후보 ID 기준이며, 실제 시설의 중복이 모두 제거됐다는 뜻은 아닙니다. 이 중 한·영·일 이름과 동일 장소를 독립 검수한 것은 4곳입니다. 나머지는 과거 공식 자료의 이름·주소·좌표 대응 조건을 통과한 후보입니다. rules-v1.json의 우선순위는 독립 identity 승인+위치 flag없음 → data_pass, unresolved duplicate/위치flag → human_review, 공식 exact name/address+모든 대응좌표≤100m+중복없음 → data_pass, 나머지 auto_hold다. 100m는 기존 triage 기준이며 현장 동일성 증명이 아니다.

3. 자동 보류

공식 출처가 아직 연결되지 않은 30,335개 기록은 자동 보류했습니다. 자료가 없거나 장소가 사라졌다는 뜻은 아닙니다. 원래 제공자의 자료를 묶음으로 연결해 다시 판정하면 되므로 전부 사람이 하나씩 확인할 필요는 없습니다.

5. 장소만 모은 목록
