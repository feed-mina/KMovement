# 장소 집합 판정 규칙과 공개 전 검증

## 1. 전체와 공개를 나눴습니다

전체 저장 40,664개 기록입니다. 실제 검색 가능한 개수는 아직 미확정입니다. 이번 작업에서 서비스 공개를 새로 승인한 장소는 0개입니다. 이는 현재 서비스에 장소가 0개라는 뜻은 아닙니다.

## 2. 자동 통과

공개 준비 자료 요건 통과는 1,652개 기록이며, 이미 동일 장소로 검수된 중복 연결만 묶으면 1,651개 후보입니다. 이 수는 후보 ID 기준이며, 실제 시설의 중복이 모두 제거됐다는 뜻은 아닙니다. 이 중 한·영·일 이름과 동일 장소를 독립 검수한 것은 4곳입니다. 나머지는 과거 공식 자료의 이름·주소·좌표 대응 조건을 통과한 후보입니다. rules-v1.json의 우선순위는 독립 identity 승인+위치 flag없음 → data_pass, unresolved duplicate/위치flag → human_review, 공식 exact name/address+모든 대응좌표≤100m+중복없음 → data_pass, 나머지 auto_hold다. 100m는 기존 triage 기준이며 현장 동일성 증명이 아니다.

## 3. 자동 보류

공식 출처가 아직 연결되지 않은 30,335개 기록은 자동 보류했습니다. 자료가 없거나 장소가 사라졌다는 뜻은 아닙니다. 원래 제공자의 자료를 묶음으로 연결해 다시 판정하면 되므로 전부 사람이 하나씩 확인할 필요는 없습니다.

## 4. 사람 확인 필요

중복이나 주소·좌표 검토가 남은 8,677개 기록을 분리했습니다. 3,313개 중복 묶음·주소좌표 보완 1,472개·공식 좌표 차이42개는 서로 겹칩니다. 합산하지 않고 장소 ID별로 한 번만 분류했습니다. 사람은 충돌 사례와 표본 검수에 집중할 수 있습니다.

## 5. 장소만 모은 목록

장소 전용 문서에서 이름·주소·공식 출처와 다국어 검수 여부를 확인할 수 있습니다. 영어·일본어 이름이 없는 곳은 미확인으로 표시했습니다. 과거 촬영지 자료의 수집일은 현재 영업을 보장하지 않습니다. 가격·아티스트 방문·예산 적합성도 미확인입니다. classification-local.jsonl은 원본 ID 전량 판정, public-preparation-candidates.json은 출처 SHA/행번호/허용 주장/금지 주장/잔여 gate를 보존한다. service-approved-set.json은 이번 신규 승인만 나타내는 빈 집합이다. 파생 집합의 canonical ID 통합은 이전 독립 검수된 연결만 사용하고 원본 ID는 legacyIds로 전부 남긴다.

## 6. 다음 통과 기준

다음 단계는 후보 목록의 최신 공식 근거 재확인과 별도 검색·답변·성능·로그인 검증입니다. 그 결과를 통과한 장소만 서비스 공개 목록으로 옮깁니다. 이번에는 목록과 분류 문서만 만들었고 원본 수정·검색 구축·실제 검색·운영 배포는 하지 않았습니다.
