# 팬 중심 아티스트 UI 개선 작업 지도

현재 단계는 조사·설계 완료이며 서비스 수정·배포는 미실행이다. 첫 수정 순서는 이름 대비 → 상세 레이아웃 → 검수된 사진 연결 → 소개와 팬 행동 → 수용 검사다.

## 확인 완료
운영 BTS API의 이름과 소개는 존재하며 사진 URL은 null이다. 기존 /artists/BTS.jpg는 HTTP200이다. 카드 자식 h3/p에는 어두운 화면용 색이 남아 있다. 소개 문구는 V114 seed와 현재 API에 동일하다.

## 담당과 순서
도우미가 가독성·상세 컴포넌트·사진 상태·저장 동선을 구현할 수 있다. 콘텐츠 검수자는 사진 출처·사용 범위·대표성과 소개의 사실을 확인해야 한다. 사용자는 지금 터미널 작업 없이 시안의 팬 관점 적합성을 볼 수 있다.
사진·문구 검수가 미완료면 임의 사실을 채우지 않는다. 구현 후 PC3종·모바일·키보드·로그인 전후·저장 실패를 확인하고 배포 단계로 진행한다. 이번 보고서 요청은 그 구현을 실행한 상태가 아니다.

## 남은 확인
현재 배포 DOM의 상세 클래스와 computed style, 사진 사용권, 대표사진 선택, 일정·상품 API의 아티스트 필터 지원, 팬5명 수용 평가는 미확인이다. 원인·명세·검증 기준의 자세한 내용은 fix-guide, 코드 없는 설명은 easy-guide에 정리했다.
