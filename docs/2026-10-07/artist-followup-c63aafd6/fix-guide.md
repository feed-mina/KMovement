# 아티스트 페이지 · 보고서 후속 수정
목표: 아티스트를 알아보고 공식 소식·내 관심·국내/해외 일정으로 자연스럽게 이동한다.

1. 지정 보고서의 사진·진한 이름·상세 2열은 기존 배포에 반영되어 있음을 확인했습니다.
2. 소식/상품 탭 주소 유지, 아티스트별 일정 왕복, 사진 로딩과 공식 소식 행동을 보완했습니다.
3. 웹만 배포하고 실제 화면과 탐색 동작을 확인했습니다.

## 현재 위치와 변경
전체 목표 → 아티스트 상세 → **소식·일정 연결과 상태 복구** 완료. 알아낸 사실은 핵심 시각 개선이 이미 배포되었다는 점입니다. 이번에 같은 수정을 중복하지 않고 남은 탐색 계약을 보완했습니다.

| 파일 | 이유와 적용 |
|---|---|
| ArtistRelated.tsx | section을 URL에서 읽고 변경. 검색어·목록 페이지 유지. artistId가 고정된 국내/해외 일정 링크 |
| FanEventFeed.tsx / ArtistReturn.tsx | 검증된 내부 아티스트 복귀 주소 표시. 기존 필터를 유지한 상세로 복귀 |

| KpopCards.tsx | 등록된 HTTPS 공식 URL이 있을 때만 공식 소식 보기 버튼. 공식 사이트에 연결하며 새 뉴스 존재를 보증하지 않음 |

## 유지한 기존 개선
출처·사용 조건이 기록된 사진 매핑, 제목 #172033·본문 #475569, 사진 contain 배치, 명시적 상세 2열, h1 이름, 비로그인 저장 안내를 유지했습니다. 사진이 없는 아티스트는 이름과 준비 안내를 유지합니다. 과거 자료 사진이 현재 멤버 구성이나 최신 활동을 의미하지 않습니다.

## 검증 결과와 한계
- 프론트 자동 검사35개·TypeScript 통과. 검색·계정 응답 경합·기존 저장 기능 회귀 포함.
- 실제 PC1366·1440·1920에서 이름·저장·공식 버튼이 첫 화면에 표시됨. 모바일390·좁은683 폭 가로 넘침 없음.
- 상품 탭 새로고침 유지, BTS 전용 일정 필터, 국내/해외 화면에서 원래 상세로 복귀, 로그인 안내 복귀 주소 통과.
- 사진 실패 응답을 주입해 이름·준비 안내가 남는 것을 확인. 정상 캡처와 장애 주입 검사를 구별합니다.
- 실제 로그인 계정의 저장 쓰기, 실제 브라우저200% 확대, 팬5명 사용성 검사는 미실행. 683px 폭 검사는 실제200% 확대의 대체 증거가 아닙니다.
- 출처·검수일이 있는 아티스트 정체성 소개와 장소 관계 데이터는 준비되지 않아 만들지 않았습니다. 검색 수치·좋은 화면이 출처 검수를 대신하지 않습니다.
