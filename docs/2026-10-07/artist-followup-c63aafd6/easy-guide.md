# 아티스트의 다음 소식으로 이어지도록 바꿨어요
목표: 좋아하는 아티스트를 보고 공식 소식과 국내·해외 일정을 쉽게 찾습니다.

1. 사진과 잘 보이는 이름은 기존 개선을 그대로 유지했어요.
2. 소식과 상품을 고른 상태를 기억하고, 아티스트의 국내·해외 일정으로 이어지게 했어요.
3. 새 화면을 반영하고 컴퓨터·휴대전화에서 확인했어요.

## 이렇게 둘러보세요
아티스트 상세 → 공식 소식 보기 또는 내 아티스트로 저장 → 소식·일정 → 국내/해외로 보기 → 아티스트로 돌아가기.
관련 상품을 선택한 뒤 새로고침해도 같은 탭이 열려요. 사진이 늦으면 불러오는 중이라고 알려주고, 실패하면 이름과 사진 준비 안내가 남아요.

## 이전과 지금
| 이전 | 지금 |
|---|---|
| 새로고침하면 소식 탭으로 돌아옴 | 선택한 소식·상품 탭 유지 |
| 아티스트 일정을 지역별로 다시 찾아야 함 | 그 아티스트의 국내·해외 일정으로 바로 연결 |
| 사진이 늦게 뜨면 상태를 모름 | 불러오는 중과 준비 중 구별 |
| 공식 사이트가 작은 링크 중 하나 | 공식 소식 보기 버튼 추가 |

## 확인한 것
자동 동작35개와 실제 컴퓨터·휴대전화 배치를 확인했어요. 상품 탭 새로고침, 아티스트 일정 왕복, 로그인 안내로 돌아오는 주소도 확인했어요.
실제 로그인해서 저장하는 마지막 동작과 팬들의 만족도는 아직 확인하지 않았어요. 공식 소개나 새로운 공연·방문 사실을 임의로 만들지 않았어요.

## 지금 할 일
터미널 명령은 필요 없어요. 아티스트 상세에서 소식·상품을 고르고 국내·해외 일정으로 이동해 보세요. 공식 소식 버튼은 등록된 공식 사이트를 열며, 새로운 공지가 있다는 약속은 아니에요.
