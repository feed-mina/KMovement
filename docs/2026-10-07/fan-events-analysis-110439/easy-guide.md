# 내 아티스트의 일정을 먼저 보는 화면
목표: 좋아하는 아티스트가 어디에서 언제 팬을 만나는지 쉽게 찾습니다.

1. 지금 화면은 날짜와 지역을 먼저 입력하게 되어 있어요.
2. 새 시안은 내 아티스트를 고른 뒤 국내·해외·온라인을 나눠 봐요.
3. 실제 화면 캡처와 예상 화면을 비교할 수 있고, 아직 서비스는 바꾸지 않았어요.

## 무엇이 불편했나요?
좋아하는 아티스트만 한 번에 모아보는 선택이 없어요. ‘서울’과 ‘일본’을 같은 지역 칸에 입력해야 해요. 날짜 규칙 설명이 길어 일정이 첫 화면 아래로 밀려요.
현재 공개 목록은 확인 시점에90건이었어요. 전체 저장 자료의 개수는 아니에요. 지역에는 도시·나라·온라인이 섞여 있어, 나누는 기준부터 확인해야 해요.

## 제안하는 사용 순서
내 아티스트 선택 → 국내·해외·온라인 선택 → 날짜순 일정 보기 → 상세와 공식 안내 확인 → 내 일정 저장.
로그인하고 아티스트를 저장했다면 ‘내 아티스트’부터, 처음 온 사람은 ‘전체 아티스트’부터 보여줘요. 로그인하지 않아도 좋아하는 아티스트를 직접 골라 공개 일정을 볼 수 있게 제안합니다.

## 국내와 해외는 이렇게 구분해요
- 국내: 대한민국에서 열리는 일정.
- 해외: 어느 국가·도시인지 확인된 해외 일정. 일본만 골라보기도 가능해요.
- 온라인: 인터넷으로 참여하는 일정. 해외로 섞지 않아요.
- 장소 미확인: 확인 중이라고 남겨요. 임의로 국내나 해외로 정하지 않아요.
해외 공연 날짜는 그 나라의 날짜를 먼저 보여줘요. 시간이 확인되면 한국 시간도 함께 볼 수 있어요. 시간이 없으면 ‘시간 미정’이라고 써요.

## 화면에서 달라지는 것
| 지금 | 예상 화면 |
|---|---|
| 날짜·지역 입력부터 시작 | 좋아하는 아티스트부터 선택 |
| 여러 나라의 일정이 한데 표시 | 국내·해외·온라인 버튼 |
| 긴 규칙 설명이 먼저 | 아티스트·날짜·장소를 먼저 |
| 관심 일정인지 알아보기 어려움 | 사진·이름과 내 일정 저장 |

## 다른 서비스에서 참고한 점
Bandsintown은 관심 아티스트와 장소·날짜로 찾는 방식을, Songkick은 도시별 날짜순 탐색을, Ticketmaster는 관심 아티스트와 이벤트 저장을 구분하는 방식을 참고했어요. 공식 도움말을 조사했으며, 세 서비스의 현재 컴퓨터 화면을 직접 사용해 본 결과는 아니에요.
대한민국/해외 버튼은 이번 요청에 맞춰 제안한 기능이에요. 모든 서비스가 똑같이 제공한다는 뜻은 아니에요.

## 시안 체험 안내
예상 화면의 공연·날짜·장소·내 아티스트 설정은 모두 가짜 예시예요. 실제 공연 일정으로 사용하면 안 돼요. 버튼을 눌러도 실제 계정에 저장되거나 서비스가 바뀌지 않아요.
사진은 출처가 기록된 공개 자료를 사용했고 시안 아래에서 출처를 볼 수 있어요.
아티스트·국내/해외·국가·월·초기화 버튼이 시안 안에서 동작하는 것과 휴대전화 폭을 검사했어요. 실제 로그인한 사람의 일정, 나라 분류, 해외 시간, 팬 만족도는 아직 검증하지 않았어요.

## 지금 할 일
터미널 명령은 필요 없어요. ‘내가 좋아하는 아티스트의 해외 일정’을 찾는 흐름이 마음에 드는지 시안을 살펴보세요.
다음 부탁말: “이 흐름을 기준으로 관심 아티스트와 국내·해외 분류에 필요한 자료를 먼저 확인하고 구현 명세를 정리해줘.”
이번 단계는 조사와 시안 보고서까지예요. 서비스는 수정하거나 배포하지 않았어요.
