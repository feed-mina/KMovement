## 어제 문서에서 달라진 기준

### 반영된 코드

팬 일정 화면·아티스트 사진 복원과 한국 날짜 기준 오늘부터 1년 기본 조회가 main에 병합됐습니다. 다시 구현할 일보다 배포 반영과 실제 조회 확인이 남았습니다.

### 여전히 확인되는 요청 차이

현재 코스 화면에도 기본 예산과 동의값의 불일치가 있습니다. 서버의 거절 조건은 직접 확인했습니다. 운영 서비스에서 같은 이유로 실패하는지는 아직 모릅니다.

### 02 · 데이터와 일정

장소·아티스트 관계·공연을 따로 관리합니다. 근거 주소와 확인일을 기록하고, 공연 시각이 없으면 동선 보장 대상으로 삼지 않습니다.

출발지·체류시간·이동시간·영업시간을 받은 뒤 시간 충돌을 검사하는 규칙을 추가할 계획입니다.

### 03 · 사진과 영상

처음에는 사용자 사진 1장으로 짧은 영상 1개를 만들고 결과가 재생되는지 봅니다. 여러 사진·음악·음성 확장은 그다음입니다.

생성 성공과 업로드 성공을 나누고, 임시 결과 보존·실패 안내·비용을 기록합니다.

### 04 · 실제 사용자 검증

해외 팬, 영어 사용자, 서울 짧은 여행은 초기 타깃 가설입니다. 실제 참여자 반응으로 수정합니다.

어제 문서의 30명·50개 코스·완료율 90%·만족도 4/5는 목표 예시이며 측정 성과가 아닙니다. 모집 규모와 비용은 실행 전에 확정합니다.

### 05 · 제안과 실증

어제 전략은 Creatrip·Trazy 등 여행 플랫폼에서 먼저 고객 문제를 확인하고, Weverse·관광기관·삼성으로 확장하는 방향입니다. 이번에 기업의 도입 의사는 확인하지 않았습니다.

소개 1장 → 데모 → 실무 검토 → 4주 실증 범위 협의 → 결과 평가 → 확대 검토. 미팅 수락과 실제 도입 승인은 다른 상태입니다.

### 1. 화면의 선택

현재 상황 · 코드 확인 / 운영 미확인

코스 화면은 기본 예산을 보내지만 일반 장소 안내 동의값을 보내지 않습니다. 서버는 이 경우 거절하도록 되어 있습니다.

내가 할 일

서울·당일치기와 미확인 조건 안내를 보여주고, 사용자가 확인한 경우에만 코스를 요청합니다. 조건을 바꾸면 새 선택으로 다시 확인합니다.

그대로 전달할 요청문

코스 화면과 첫 설정 화면에서 같은 조건을 보내게 해줘. 동의 전에는 안내하고, 동의를 자동으로 켜지 마. 지원하지 않는 지역과 기간도 구체적으로 알려줘.

끝났는지 확인하는 법

동의 전 안내, 동의 후 요청, 지원 범위 밖 안내를 각각 확인한 결과.

실패하면 할 일

동의 뒤에도 실패하면 지역과 기간, 로그인 여부를 나눠 확인합니다.

아직 모르는 것: 배포 환경에서의 실제 결과. 다음 확인: 위 사례를 같은 기준 버전으로 실행해 증거를 남깁니다.

### 2. 서버로 전달

현재 상황 · 코드 확인 / 운영 미확인

화면에 따라 서버로 전달하는 내용과 경로가 다릅니다. 전달 중 선택이 바뀌면 같은 기능처럼 보여도 결과가 달라질 수 있습니다.

내가 할 일

같은 코스 만들기는 같은 규칙으로 전달하고, 기존 코스 설명과 새 코스 생성을 구별합니다.

그대로 전달할 요청문

화면에서 고른 값이 서버에 도착할 때까지 대조해줘. 코스 만들기와 코스 설명을 같은 작업으로 처리하지 마. 로그인 정보가 없으면 로그인 안내를 보여줘.

끝났는지 확인하는 법

입력값·전달값·서버 판정이 연결된 결과표. 로그인 만료는 별도 안내.

실패하면 할 일

어느 화면에서 시작했는지부터 기록하고, 값이 달라지는 전달 단계를 찾습니다.

아직 모르는 것: 배포 환경에서의 실제 결과. 다음 확인: 위 사례를 같은 기준 버전으로 실행해 증거를 남깁니다.

### 3. 장소 검색

현재 상황 · 코드 확인 / 운영 미확인

지역 이름을 찾는 처리와 장소 검색은 있지만, “종로 제외” 같은 부정 조건을 별도 조건으로 전달하는 구조는 부족합니다.

내가 할 일

포함 지역·제외 지역·제외 장소를 따로 정리합니다. 먼저 조건에 맞는 장소를 고른 뒤 이름과 뜻을 비교합니다.

그대로 전달할 요청문

종로 제외와 특정 장소 제외를 따로 처리해줘. 결과가 없으면 내 조건을 몰래 풀지 마. 한국어·영어·일본어에서 같은 뜻인지 확인해줘.

끝났는지 확인하는 법

명시적으로 제외한 장소 노출 0건, 언어별 정답률과 새 질문 평가 결과.

실패하면 할 일

조건 해석, 후보 제한, 이름 검색, 의미 검색 중 어디서 실패했는지 분리합니다.

### 4. 근거와 일정

현재 상황 · 코드 확인 / 운영 미확인

현재 코드는 장소 목록과 출처를 다시 대조합니다. 하지만 주소가 맞는다는 사실만으로 아티스트 방문·가격·영업시간까지 확인되지는 않습니다.

내가 할 일

장소의 존재, 아티스트 관계, 현재 가격과 시간에 각각 근거를 붙입니다. 모르는 값은 모른다고 표시합니다.

그대로 전달할 요청문

출처 없는 아티스트 방문이나 가격을 단정하지 마. 기존 코스를 설명할 때 새 코스로 바꾸지 마. 공연 시각과 이동시간은 확인된 자료가 있을 때만 일정에 적용해줘.

끝났는지 확인하는 법

장소·관계·가격·시간을 나눈 검수표. 같은 코스 설명과 새 코스 만들기의 구분.

실패하면 할 일

시간이 없으면 “공연 지각 방지 보장”을 표시하지 않습니다. 출처가 만료되면 코스 재확인을 안내합니다.

아직 모르는 것: 배포 환경에서의 실제 결과. 다음 확인: 위 사례를 같은 기준 버전으로 실행해 증거를 남깁니다.

### 5. 중단과 비용

현재 상황 · 코드 확인 / 운영 미확인

현재 유료 대화·코스 생성에는 자동 재시도 없음 규칙이 있습니다. 연결 실패와 사용자 중단은 서로 다른 상태로 보여야 합니다.

내가 할 일

실패 단계를 기록하고, 사용자가 다시 요청할 때 중복 응답과 중복 비용이 없는지 확인합니다.

그대로 전달할 요청문

지금의 사용량 한도와 자동 재시도 없음 규칙을 유지해줘. 연결 실패·답변 도중 실패·사용자 중단을 나누고 중단 뒤 답변이 붙지 않는지 확인해줘.

끝났는지 확인하는 법

실패 유형별 화면과 요청 기록. 중복 답변·한도 초과 없음.
