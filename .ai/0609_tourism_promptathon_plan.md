## 1. 한 줄 정의 (Service One-liner)

> **"좋아하는 K-POP 아티스트의 발자취를 따라, 여행을 떠나기 전엔 AI가 성지순례 코스를 짜주고, 다녀온 뒤엔 사진 한 장으로 추억 영상을 만들어주는 — K-컬처 여행 풀사이클 AI 동반자."**

- **Before (계획)**: 아티스트·지역·목적·예산 → KTO OpenAPI 관광데이터 + 촬영지 매핑 → AI 맞춤 일정·동선
- **After (기록)**: 여행 사진/스케치 → 생성형 AI 추억 영상(내레이션 + BGM) → 커뮤니티 공유
- **차별점**: 대부분의 관광 서비스가 "계획"에서 끝나는데, 우리는 **여행의 감정적 마무리(추억 영상)까지** 닫는 유일한 풀사이클.

## 2. 문제 정의 (심사 '기획력' 30점 직결)

| 단계 | 문제 (Pain) | 기존 방식의 한계 | 우리의 해결 |
|------|-------------|-----------------|-------------|
| Discover | "최애 뮤비/예능에 나온 그 장소 가보고 싶은데 어딘지 모르겠다" | 팬덤 커뮤니티 검색에 산재, 비공식·부정확 | 아티스트→촬영지 매핑 + KTO 공식 관광데이터 결합 |
| Analyze | 외국인 팬은 한국어 정보 장벽 + 동선/혼잡/예산 계획 어려움 | 번역기·블로그 짜깁기, 신뢰도 낮음 | KTO **다국어 관광정보 API** + AI 일정 자동 생성 |
| Agent Thinking | 여행 후 사진은 갤러리에 묻히고 추억이 흩어짐 | 수동 영상편집은 진입장벽 높음 | 사진 1장 → 생성형 AI 추억 영상 자동 제작 |

**핵심 인사이트**: K-POP 인바운드 관광은 폭발적으로 성장 중이지만, "어디를(촬영지)·어떻게(동선)·무엇을 남길지(추억)"를 한 번에 풀어주는 서비스가 없다.

## 4. ennoia 에이전트 워크플로우 설계 (신규 구축안)

ennoia는 "프롬프트 + RAG + API 커넥터 + Agent Workflow"를 노코드로 엮는 플랫폼이므로,
K-Ride의 복잡한 백엔드를 그대로 옮기지 말고 **핵심 흐름만 에이전트 워크플로우로 재현**한다.

### 4.1 입력 변수 (Variables)
```
${artist}    선택 아티스트 (예: BTS, NewJeans)        — INTRO2 대응
${region}    여행 지역 (최대 2곳)                      — INTRO3 대응
${duration}  여행 기간 (당일/1박2일/2박3일)            — INTRO1 대응
${purpose}   여행 목적 (K-컬처/맛집/자연/역사/쇼핑/휴식) — INTRO4 대응
${budget}    예산 범위                                 — INTRO5 대응
${language}  출력 언어 (ko/en/ja/zh-CN/zh-TW/...)       — 다국어 토글
${companion} 동반 유형 (혼자/가족/반려동물/휠체어)      — 무장애·반려동물 분기
```

### 4.2 워크플로우 노드 (Before — 여행 플래너)
```
[1] 입력 수집 (Variables)
      │
[2] RAG 검색 — "아티스트 → 촬영지/성지" 매핑 문서
      │   (뮤비·예능·화보 촬영지, 팬 성지 → 좌표/지명)
      ▼
[3] API 커넥터 — KTO 다국어 관광정보 서비스
      │   areaBasedList / locationBasedList / searchKeyword
      │   → ${language}에 따라 영문/일문/중문 엔드포인트 분기
      ▼
[4] API 커넥터 — 관광지별 연관관광지 정보 서비스
      │   → 성지 주변 연계 코스 자동 확장
      ▼
[5] API 커넥터 — 관광지 집중률/방문자 추이 예측
      │   → 혼잡 시간대 회피 + 방문 순서 최적화
      ▼
[6] (조건 분기) companion = 휠체어 → 무장애 여행 정보 API
      │           companion = 반려동물 → 반려동물 동반여행 API
      ▼
[7] LLM 노드 — 일정/동선 생성 프롬프트
      │   입력: 위 데이터 + 변수 / 출력: 일자별 타임라인 + 이동·예산·이유(reason)
      ▼
[8] 출력 — 맞춤 일정 카드 + 지도용 좌표 + 다음 액션(영상 만들기) 안내
```

### 4.3 워크플로우 노드 (After — 추억 영상)
```
[A] 사용자 사진/스케치 업로드 + (선택)한 줄 메모
      │
[B] (메모 없을 때) 이미지 캡셔닝 → 내레이션 소재 생성
      │   ※ K-Ride에 BLIP2 기반 자동 캡션 로직 존재 (498a5b2a)
      ▼
[C] LLM 노드 — 방문지 컨텍스트 결합 내레이션 스크립트
      │   (KTO 오디오가이드/관광사진 API 텍스트를 RAG로 보강)
      ▼
[D] 영상 생성 — 사진→모션(I2V) + TTS 내레이션 + BGM
      │   ※ ennoia 단독으로 영상 생성이 어려우면:
      │     - 데모용: K-Ride 미디어 파이프라인(RunPod/Cloudinary) URL 임베드
      │     - 또는 사전 제작 샘플 영상으로 결과 시연
      ▼
[E] 출력 — 추억 영상 + 커뮤니티 공유 카드
```

> **현실적 팁**: ennoia는 텍스트/이미지 생성·API 연동에 강하므로, Before(플래너)는 **ennoia에서 완전 구현**하고, After(영상)는 **내레이션 스크립트·스토리보드까지 ennoia가 생성** + 실제 렌더링은 K-Ride 파이프라인 결과를 데모로 보여주는 하이브리드가 마감 대비 안전.

## 6. STEP 01 제출폼 답변 초안

> 그대로 복사해 다듬어 사용하세요.

**① 서비스 제목**
> K-Ride : K-POP 성지순례부터 추억 영상까지, 여행 풀사이클 AI 동반자

**② 서비스 내용 요약**
> K-Ride는 좋아하는 K-POP 아티스트를 선택하면, 한국관광공사 OpenAPI의 다국어 관광데이터와 촬영지 매핑을 결합해 **성지순례 맞춤 일정·동선을 자동 생성**합니다. 여기에 연관관광지·방문자 집중률 예측 데이터를 더해 혼잡을 피하고 동선을 최적화합니다. 여행을 다녀온 뒤에는 사진 한 장만 올리면 **생성형 AI가 내레이션과 음악이 입혀진 추억 영상**을 만들어 줍니다. '계획 → 여행 → 추억'의 전 과정을 하나의 AI 흐름으로 닫는 K-컬처 여행 서비스입니다.

**③ 주제 선정 이유**
> K-POP 인바운드 관광이 급성장하지만 "내 최애가 다녀간 장소"를 신뢰도 있게 찾아 동선·예산까지 계획해 주는 서비스가 없고, 여행 후 추억은 갤러리에 흩어진다는 불편에서 출발했습니다. 공식 관광데이터(KTO OpenAPI)와 생성형 AI를 결합하면 이 공백을 메울 수 있다고 보았습니다.

**④ 타겟 사용자**
> 전세계 K-POP 팬(인바운드 외국인) 1차, 국내 K-컬처 여행객 2차. 다국어 토글과 무장애·반려동물 동반 옵션으로 가족·단체까지 포용.

**⑤ 시행착오·개선 시도** (작성 예시 — 실제 경험으로 교체)
> 초기에는 LLM이 촬영지를 임의로 지어내는(hallucination) 문제가 있어, 촬영지 매핑을 RAG 문서로 고정하고 KTO API의 실제 관광지 데이터와 교차 검증하도록 프롬프트를 재설계했습니다. 또 일정이 동선을 무시하고 나열되던 문제는 연관관광지·집중률 데이터를 먼저 조회해 방문 순서를 정하도록 워크플로우 순서를 바꿔 해결했습니다.

## 8. 고도화 로드맵 (확장성 — 결선 35점 핵심)

1. **실시간 혼잡·날씨 연동**: 집중률 예측 + (K-Ride 보유) Weather LSTM → 당일 동선 재배치
2. **GraphRAG 성지 네트워크**: 아티스트-장소-지역 그래프(K-Ride Neo4j)로 "같이 가면 좋은 성지" 추천 고도화
3. **다국어 추억 영상**: 내레이션을 ${language}별 TTS로 — 글로벌 팬 SNS 바이럴 루프
4. **콘서트·페스티벌 캘린더 연동**: 공연 일정 + 주변 관광 패키지
5. **로컬 상생**: 관광인 채용/지역 소상공인 데이터 연계로 지역경제 환류
6. **B2B 확장**: 지자체·소속사 팬미팅 투어 패키지 자동 생성 (차기 웹/앱 부문 시드)
