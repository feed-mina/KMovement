# 챗봇 플로팅(Floating) 모달 구현 계획

사용자님의 피드백을 반영하여, 전체 화면을 덮는 방식이 아닌 **우측 하단에 떠 있는 형태(Floating)**의 채팅창으로 구현 계획을 수정했습니다.

## 제안하는 변경 사항

### 1. 플로팅 모달 상태 및 위치 구현
- `app/view/[...slug]/page.tsx`에 `isChatModalOpen` 상태를 추가하고, FOCUS 화면 진입 시 **기본값으로 `true`**(열린 상태)가 되도록 설정합니다.
- 화면 우측 하단(파란색 박스 위치)에 고정된 크기(예: 너비 360px, 높이 600px)의 모달 창을 띄웁니다.

### 2. 'AI 여행봇 채팅' 버튼 동작 수정
- 버튼 텍스트를 "AI 여행봇과 상담"에서 "AI 여행봇 채팅"으로 변경합니다. (데이터베이스 마이그레이션 V59 스크립트 작성)
- 이 버튼을 누르면 채팅방 페이지(`/view/CHAT`)로 이동하는 대신, `isChatModalOpen` 상태를 반전(Toggle)시켜 모달이 열려있으면 숨기고, 숨겨져 있으면 다시 열리도록 `handleAction`을 수정합니다.

### 3. 채팅 컴포넌트 닫기 동작 업데이트
- `KrideChatComponent.tsx`에 닫기 함수(`onCloseModal`)를 연결합니다.
- 채팅창 상단의 "X" 버튼을 누르면 챗봇 모달이 닫히고(숨김 처리) 채팅 내용은 리셋됩니다.
- 다시 "AI 여행봇 채팅" 버튼을 누르면 새롭게 채팅을 시작할 수 있습니다.
